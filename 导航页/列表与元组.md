> **说明**:列表与元组是 Python 中最核心的序列类型,用于存储和操作有序数据集合.列表是可变的,适合动态增删改;元组是不可变的,适合存储固定数据.本模块系统讲解列表与元组的定义,操作,数值列表生成,序列转换及综合应用,是数据结构学习的起点.

#### 核心概念思维导图

```
列表与元组
├── 列表(list)—— 可变序列
│   ├── 增:append, insert, extend
│   ├── 删:del, pop, remove
│   ├── 改:索引赋值
│   ├── 查:in, index, count
│   ├── 排序:sort, sorted
│   ├── 切片:list[start:end:step]
│   └── 复制:copy, list[:], copy.deepcopy
├── 数值列表
│   ├── 列表生成式:[expr for x in iterable if condition]
│   ├── 嵌套生成式:[expr for i in range(m) for j in range(n)]
│   └── 统计:min, max, sum
├── 元组(tuple)—— 不可变序列
│   ├── 定义:(1, 2, 3) 或 1, 2, 3
│   ├── 单元素元组:(1,) 需加逗号
│   └── 适用场景:函数返回值,字典键
└── 序列转换
    ├── list(iterable) / tuple(iterable)
    ├── zip() —— 并行迭代
    └── enumerate() —— 索引+值
```

#### 常见应用场景

| 场景 | 推荐类型 | 原因 |
|------|----------|------|
| 存储动态数据(如用户列表) | `list` | 可变,可增删改 |
| 坐标点,RGB颜色 | `tuple` | 固定结构,不可变 |
| 函数返回多个值 | `tuple` | 自动打包 |
| 字典键 | `tuple` | 需不可变类型 |
| 大批量数值计算 | `list` + NumPy(后序) | 列表存储,NumPy加速 |
| 遍历索引和值 | `enumerate(list)` | 高效获取 |
