> **说明**:字典与集合是 Python 中基于**哈希表**实现的高效数据结构,字典以键值对(key-value)形式存储映射关系,适合快速查找,统计与关联数据;集合是无序不重复元素的容器,擅长去重与集合运算(交,并,差,对称差),本模块系统讲解字典与集合的定义,操作与综合应用,是学习算法与数据处理的重要一环,

#### 与数学/算法的关联

| 概念 | 数学对应 | 算法应用 |
|------|----------|----------|
| 字典(dict) | 映射(函数) $f: K \to V$ | 查找表,缓存,词频统计,图邻接表 |
| 集合(set) | 集合论(外延公理) | 去重,关系测试,图论中的顶点集 |
| 并集(`\|`) | $A \cup B$ | 合并两个集合 |
| 交集(`&`) | $A \cap B$ | 共同元素查询 |
| 差集(`-`) | $A \setminus B$ | 排除部分元素 |
| 对称差(`^`) | $A \triangle B$ | 仅属于其中一个集合的元素 |

#### 核心概念思维导图

```
字典与集合
├── 字典(dict)—— 键值对映射
│   ├── 定义:{key: value} 或 dict()
│   ├── 键:必须不可变(字符串,数字,元组)
│   ├── 增/改:d[key] = value
│   ├── 删:del d[key], pop(key), popitem(), clear()
│   ├── 查:d[key] 或 d.get(key, default)
│   ├── 遍历:items(), keys(), values()
│   ├── 合并:update() 或 dict(d1, **d2)
│   └── 排序:sorted(d.items(), key=lambda x: x[1])
├── 集合(set)—— 无序不重复元素集
│   ├── 定义:{elem1, elem2} 或 set(iterable)
│   ├── 元素:必须不可变
│   ├── 操作:add(), remove(), discard(), pop()
│   ├── 并集:| 或 union()
│   ├── 交集:& 或 intersection()
│   ├── 差集:- 或 difference()
│   └── 对称差:^ 或 symmetric_difference()
└── 综合应用
    ├── 词频统计(字典计数)
    ├── 去重(集合自动去重)
    ├── 关系判断(集合成员运算)
    └── 排行榜筛选(字典 + 排序)
```

#### 典型应用场景与对应操作

| 应用场景 | 推荐结构 | 关键操作 |
|----------|----------|----------|
| 词频统计 | `dict` | `d[word] = d.get(word, 0) + 1` |
| 去重 | `set` | `set(list)` 去重 |
| 数据去重后保持顺序 | `dict.fromkeys(list)` | 利用字典键去重 |
| 两表共同元素 | `set` 交集 | `set_A & set_B` |
| 查找表/缓存 | `dict` | 键快速查找 $O(1)$ |
| 图邻接表 | `dict` + `list`/`set` | `{顶点: [邻接顶点]}` |
| 两个映射合并 | `dict` | `d1.update(d2)` 或 `{**d1, **d2}` |
