#### 核心概念思维导图

```
文件
├── 核心概念
│   ├── 文件路径:绝对路径 / 相对路径
│   ├── 文件类型:文本文件 / 二进制文件
│   └── 文件操作三步:打开 → 读写 → 关闭
├── 文件基本操作
│   ├── 打开:open(路径, 模式)
│   │   ├── 读模式 'r'(默认)
│   │   ├── 写模式 'w'(覆盖)
│   │   ├── 追加模式 'a'
│   │   └── 读写模式 'r+' / 'w+' / 'a+'
│   ├── 读方法:read(), readline(), readlines()
│   ├── 写方法:write(), writelines()
│   ├── 关闭:close()
│   └── 上下文管理器:with ... as ...(自动关闭)
├── CSV 文件操作
│   ├── 特点:纯文本,记录组成,分隔符(逗号/分号/制表符)
│   ├── 读取:csv.reader() → 逐行返回列表
│   ├── 写入:csv.writer() → writerow() / writerows()
│   ├── 参数:newline='' 避免多余空行
│   └── 编码:encoding='utf-8' 处理中文
└── 典型应用
    ├── 数据持久化(结果保存)
    ├── 配置文件读写
    ├── 数据导入导出(CSV ↔ 程序数据)
    └── 大批量数据的逐行处理
```

#### 典型应用场景

| 场景 | 文件类型 | 关键操作 |
|------|----------|----------|
| 保存程序结果 | 文本文件 | `write()` / `writelines()` |
| 读取实验数据 | 文本文件 | `read()` / `readlines()` |
| 表格数据导入 | CSV | `csv.reader` + 逐行处理 |
| 数据导出备用 | CSV | `csv.writer` + `writerows()` |
| 日志记录 | 文本文件(追加模式) | `'a'` 模式 + `write()` |
| 配置文件 | 文本文件 | `read()` + 解析 |

#### 数据处理流程中的文件角色

在数学/算法工作的数据流中,文件处于如下位置:

```
原始数据(CSV/文本)→ 文件读取 → Python 数据结构 → 计算处理 → 文件写入 → 结果数据
       ↑                                        ↓
   (外存持久化)                          (外存持久化)
```

> CSV 文件特别重要,因为它是数据分析,机器学习中最常见的数据交换格式之一,也是 Python 与 Excel,数据库,统计软件之间传递表格数据的桥梁.

#### 核心概念补充

##### 绝对路径 vs 相对路径
- **绝对路径**:从盘符(或根目录)开始完整描述位置,如 `F:\documents\python\data.txt`.
- **相对路径**:从当前工作目录(CWD)开始,如 `data.txt` 或 `./data/data.txt`.

```python
import os
print(os.getcwd())          # 查看当前工作目录
os.chdir("F:/documents")    # 修改工作目录
```

##### 文件打开模式速查

| 模式 | 含义 |
|------|------|
| `'r'` | 只读(文件必须存在) |
| `'w'` | 只写(覆盖,不存在则创建) |
| `'a'` | 追加(文件末尾写入) |
| `'r+'` | 读写(文件必须存在) |
| `'w+'` | 读写(覆盖,不存在则创建) |
| `'a+'` | 读写(追加) |
| `'b'` | 二进制模式(如 `'rb'`,`'wb'`) |
| `'t'` | 文本模式(默认) |
