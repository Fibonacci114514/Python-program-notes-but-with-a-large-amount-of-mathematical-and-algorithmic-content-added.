> **摘要**:字符串是 Python 中最常用的序列类型之一,用于存储和操作文本数据.本文系统介绍字符串的定义方式,索引与切片,内置运算符,常用处理函数与方法,以及格式化输出的高级用法.字符串在数据清洗,文本分析,自然语言处理等场景中具有广泛应用,是算法与数据处理的基本功.

---

#### 1. 字符串的定义

字符串(`str`)是用引号括起来的字符序列.Python 支持四种定义方式:

| 方式 | 语法 | 特点 |
|------|------|------|
| 单引号 | `'文本'` | 可包含双引号 |
| 双引号 | `"文本"` | 可包含单引号 |
| 三单引号 | `'''多行'''` | 可跨行,保留换行 |
| 三双引号 | `"""多行"""` | 可跨行,保留换行 |

```python
name = input("姓名:")
country = input("国家:")
s = "世界那么大," + name + "想去" + country + "看看"
print(s)   # 字符串拼接
```

> **提示**:三引号常用于多行注释,长文本或文档字符串(docstring).

#### 2. 索引与切片(核心操作)

字符串是 **有序序列**,支持两种索引体系:

| 索引方向 | 起始值 | 示例(`s = "Python"`) |
|----------|--------|------------------------|
| 正向递增 | 0, 1, 2, ... | `s[0]` → `'P'` |
| 反向递减 | -1, -2, -3, ... | `s[-1]` → `'n'` |

##### 2.1 切片语法

```python
s[起始:结束:步长]
```

- **起始**:包含,缺省表示从开头开始.
- **结束**:不包含,缺省表示到末尾.
- **步长**:正数表示从左到右,负数表示从右到左.

```python
s = "Hello Mike"
print(s[0:5])       # Hello(正向取前5个字符)
print(s[0:6:2])     # Hlo(取索引0,2,4)
print(s[::-1])      # ekiM olleH(反转字符串)
print(s[::-3])      # eMlH(反向步长3)
```

##### 2.2 实战:月份名称缩写

将 12 个月份的英文缩写存入一个字符串,用切片提取:

```python
months = "JanFebMarAprMayJunJulAugSepOctNovDec"
m = int(input("输入月份(1-12):"))
pos = (m - 1) * 3
print(months[pos:pos+3])
```

#### 3. 内置字符串运算符

| 运算符 | 描述 | 示例 |
|--------|------|------|
| `+` | 拼接 | `"AB" + "123"` → `"AB123"` |
| `*` | 重复 | `"Tom" * 3` → `"TomTomTom"` |
| `in` | 成员判断(子串) | `"H" in "Hello"` → `True` |

```python
s = "Python"
print("Py" in s)   # True
print("java" in s) # False
```

#### 4. 内置字符串处理函数

| 函数 | 描述 | 示例 |
|------|------|------|
| `len(s)` | 返回字符串长度 | `len("abc")` → 3 |
| `str(x)` | 将对象转为字符串 | `str(123)` → `"123"` |
| `chr(x)` | Unicode 编码 → 字符 | `chr(65)` → `'A'` |
| `ord(c)` | 字符 → Unicode 编码 | `ord('A')` → 65 |
| `hex(x)` | 整数 → 十六进制字符串 | `hex(255)` → `'0xff'` |
| `oct(x)` | 整数 → 八进制字符串 | `oct(8)` → `'0o10'` |

**Unicode 编码规律**:

```python
print(ord('A'), ord('B'), ord('C'))   # 65 66 67
print(ord('a'), ord('b'), ord('c'))   # 97 98 99
print(ord('0'), ord('1'), ord('2'))   # 48 49 50
```

- 大写字母连续,小写字母连续,数字连续.
- 小写字母编码 > 大写字母编码.

#### 5. 字符串常用方法(重要)

字符串是 **不可变** 对象,所有“修改”方法都返回新字符串,原字符串不变.

##### 5.1 查找类

| 方法 | 描述 |
|------|------|
| `find(sub)` | 返回首次出现位置,不存在返回 -1 |
| `rfind(sub)` | 返回最后一次出现位置,不存在返回 -1 |
| `index(sub)` | 同 `find`,但不存在时抛出 `ValueError` |
| `rindex(sub)` | 同 `rfind`,但不存在时抛出异常 |
| `count(sub)` | 返回子串出现次数 |

```python
s = "hello world"
print(s.find("o"))      # 4
print(s.rfind("o"))     # 7
print(s.count("l"))     # 3
```

##### 5.2 分割与连接

| 方法 | 描述 |
|------|------|
| `split(sep)` | 按分隔符分割为列表(默认按空白) |
| `rsplit(sep)` | 从右端开始分割 |
| `join(iterable)` | 用指定字符连接多个字符串 |

```python
# 分割
s = "a,b,c,d"
parts = s.split(",")      # ['a', 'b', 'c', 'd']

# 连接
words = ["Python", "is", "fun"]
result = "-".join(words)  # 'Python-is-fun'
```

##### 5.3 大小写转换

| 方法 | 描述 |
|------|------|
| `lower()` | 全转小写 |
| `upper()` | 全转大写 |
| `capitalize()` | 首字母大写 |
| `title()` | 每个单词首字母大写 |
| `swapcase()` | 大小写互换 |

```python
s = "I have two big eyes."
print(s.lower())      # i have two big eyes.
print(s.upper())      # I HAVE TWO BIG EYES.
print(s.title())      # I Have Two Big Eyes.
```

##### 5.4 替换与清洗

| 方法 | 描述 |
|------|------|
| `replace(old, new)` | 替换子串 |
| `strip([chars])` | 删除两端指定字符(默认空白) |
| `lstrip()` | 删除左端字符 |
| `rstrip()` | 删除右端字符 |

```python
s = "    abc   "
print(s.strip())        # 'abc'
print(s.replace(" ", ""))  # 'abc'

s2 = "=====Mike====="
print(s2.strip('='))    # 'Mike'
```

##### 5.5 判断类(返回布尔值)

| 方法 | 描述 |
|------|------|
| `startswith(prefix)` | 是否以某前缀开头 |
| `endswith(suffix)` | 是否以某后缀结尾 |
| `isupper()` | 是否全大写字母 |
| `islower()` | 是否全小写字母 |
| `isdigit()` | 是否全数字字符 |
| `isalpha()` | 是否全字母 |
| `isalnum()` | 是否全字母或数字 |

```python
s = "Python程序设计.py"
print(s.startswith("Python"))   # True
print(s.endswith(".py"))        # True

s2 = "2024"
print(s2.isdigit())             # True
```

#### 6. `format()` 格式化方法

##### 6.1 位置与索引填充

```python
# 默认按顺序填充
"我是{}班{}号的学生{}".format("化工1701", 28, "赵帅")
# '我是化工1701班28号的学生赵帅'

# 指定索引顺序
"我是{1}班{2}号的学生{0}".format("赵帅", "化工1701", 28)
# '我是化工1701班28号的学生赵帅'
```

##### 6.2 格式说明符

语法:`{ : 填充字符 对齐方式 宽度 .精度 类型 }`

| 对齐方式 | 含义 |
|----------|------|
| `<` | 左对齐 |
| `>` | 右对齐 |
| `^` | 居中对齐 |

```python
# 宽度与对齐
print("{:*^20}".format("Mike"))   # ********Mike********
print("{:=<20}".format("Mike"))   # Mike================

# 浮点数精度
print("{:.2f}".format(3.1415926)) # 3.14
print("{:.4f}".format(3.1415926)) # 3.1416

# 整数宽度
print('{:5d}'.format(24))         # '   24'
print('{:x>5d}'.format(24))       # 'xxx24'
```

> 在 Python 3.6+ 中,推荐使用更简洁的 **f-string**:
> ```python
> name = "Mike"
> print(f"{name:*^20}")   # ********Mike********
> ```

#### 7. 与数学/算法的关联

| 应用场景 | 字符串方法/操作 |
|----------|----------------|
| 数据清洗 | `strip()`, `replace()`, `split()` |
| 文本特征提取 | `lower()`, `split()`, `join()` |
| 密码/验证码生成 | 字符串拼接 + `chr()` + `random` |
| 文件解析 | `split()`, `startswith()`, `find()` |
| 自然语言处理(NLP) | 分词,正则表达式(`re` 模块),编码转换 |
| 算法题常用操作 | 反转(`[::-1]`),回文判断,字符统计 |

**示例:判断回文**

```python
s = input("请输入字符串:")
if s == s[::-1]:
    print("是回文")
else:
    print("不是回文")
```
