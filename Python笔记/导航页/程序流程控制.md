> **说明**:程序流程控制是算法的骨架.任何复杂的计算过程,都可以分解为**顺序执行**,**条件分支**和**循环迭代**三种基本结构的组合.本模块从条件构建开始,系统讲解分支与循环的语法,并补充异常处理,随机数生成,时间操作等实用工具,最终通过综合案例融会贯通.

---

#### 模块概览

本模块围绕“程序如何决定下一步做什么”这一核心问题展开,共包含 7 个子主题,按 **“基础 → 工具 → 综合”** 三层递进组织:

| 层级 | 子主题 | 核心内容 |
|------|--------|----------|
| **基础层** | [[条件表达式]] | 关系运算,逻辑运算,构建布尔条件 |
| | [[选择结构]] | `if` / `if-else` / `if-elif-else` 分支逻辑 |
| | [[循环结构]] | `for` / `while` 迭代,`break` / `continue`,循环嵌套 |
| **工具层** | [[异常和异常处理]] | `try-except` 捕获运行时错误,提升程序健壮性 |
| | [[random库的使用]] | 随机数生成,用于模拟与概率实验 |
| | [[time、datetime库的使用]] | 计时,格式化时间,用于性能测量与日志 |
| **综合层** | [[综合应用]] | 经典算法题实战(水仙花数,完全数,级数求和,斐波那契数列) |

#### 学习路径建议

##### 主线(必学)
1. **构建条件** → [[条件表达式]]:掌握如何写出正确的布尔判断.
2. **分支** → [[选择结构]]:让程序根据条件选择不同路径.
3. **循环** → [[循环结构]]:让程序重复执行,这是算法中最重要的迭代能力.

##### 支线(强化)
4. **异常处理** → [[异常和异常处理]]:处理用户输入错误,文件不存在等预期外情况.
5. **随机与时间** → [[random库的使用]] | [[time、datetime库的使用]]:为程序加入不确定性,计时功能,常用于模拟与性能测试.

##### 终点
6. **综合实战** → [[综合应用]]:运用上述所有知识,解决经典的数学与算法问题.

#### 核心概念思维导图

```
程序流程控制
├── 顺序结构(隐式,逐行执行)
├── 分支结构
│   ├── 条件表达式(关系/逻辑运算符)
│   ├── if, if-else, if-elif-else
│   └── 嵌套分支
├── 循环结构
│   ├── for(确定次数迭代)
│   ├── while(条件迭代)
│   ├── break / continue
│   ├── for-else / while-else
│   └── 循环嵌套
├── 异常处理
│   └── try-except-else-finally
└── 辅助工具
    ├── random(随机数)
    ├── time / datetime(计时)
    └── 综合应用(经典算法)
```

#### 常见算法模式与本模块的对应

| 算法模式 | 使用的流程控制结构 | 示例问题 |
