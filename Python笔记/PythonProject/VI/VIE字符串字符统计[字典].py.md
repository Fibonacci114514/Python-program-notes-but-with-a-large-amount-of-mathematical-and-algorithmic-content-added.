# `VIE字符串字符统计[字典].py` · 字符频率统计（字典版，推荐）

> **摘要**：使用字典统计字符出现频率，利用 `dict.get(key, 0)` 方法优雅地处理字符首次出现的情况。这是最 Pythonic 的统计方式，也是后续词频统计的基础。

---

#### 💻 代码

```python
sentence = input()
sentence = sentence.lower()
counts = {}
for c in sentence:
    counts[c] = counts.get(c, 0) + 1
print(counts)
```

---

#### 📖 运行示例

**输入**：`Hello World`

**输出**：
```
{'h': 1, 'e': 1, 'l': 3, 'o': 2, ' ': 1, 'w': 1, 'r': 1, 'd': 1}
```

---

#### 📐 代码拆解

##### 核心语句
```python
counts[c] = counts.get(c, 0) + 1
```

| 场景 | `counts.get(c, 0)` | 执行后 |
| :--- | :--- | :--- |
| 字符首次出现 | 返回 `0` | `counts[c] = 1` |
| 字符已存在 | 返回当前次数 $k$ | `counts[c] = k + 1` |

##### 算法复杂度
- **时间复杂度**：$O(n)$
- **空间复杂度**：$O(k)$，$k$ 为不同字符数
