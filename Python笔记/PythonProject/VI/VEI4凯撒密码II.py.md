# `VEI4凯撒密码II.py` · 凯撒密码（映射表版，支持字母+数字）

> **摘要**：构造三个映射表（小写字母、大写字母、数字），对用户输入的字符串进行凯撒移位加密。这是 `VEI6` 映射表构造器的完整应用。

---

#### 💻 代码

```python
f1 = {}
f2 = {}
f3 = {}
dx = int(input())

# 小写字母映射
for i in range(26):
    f1[chr(i + ord('a'))] = chr((i + dx) % 26 + ord('a'))

# 大写字母映射
for i in range(26):
    f2[chr(i + ord('A'))] = chr((i + dx) % 26 + ord('A'))

# 数字映射
for i in range(10):
    f3[chr(i + ord('0'))] = chr((i + dx) % 10 + ord('0'))

s = input()
s1 = ''
for i in s:
    if i.islower():
        s1 += f1[i]
    elif i.isupper():
        s1 += f2[i]
    elif i.isdigit():
        s1 += f3[i]
    else:
        s1 += i
print(s1)
```

---

#### 📖 运行示例

**输入**：
```
3
Hello World 2024
```

**输出**：
```
Khoor Zruog 5357
```

---

#### 📐 算法分析

| 映射表 | 字符范围 | 移位公式 |
| :--- | :--- | :--- |
| `f1` | `'a'` ~ `'z'` | $(i + dx) \bmod 26$ |
| `f2` | `'A'` ~ `'Z'` | $(i + dx) \bmod 26$ |
| `f3` | `'0'` ~ `'9'` | $(i + dx) \bmod 10$ |

**优点**：通过查表（字典）进行加密，速度快，且易于支持解密（构造反向映射表即可）。
