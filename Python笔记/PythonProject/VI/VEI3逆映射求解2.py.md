# `VEI3逆映射求解2.py` · 字典逆映射（`items()` 版本）

> **摘要**：与 `VEI3逆映射求解.py` 功能相同，但使用 `items()` 方法遍历字典，代码更简洁、更 Pythonic。

---

#### 💻 代码

```python
a = eval(input())
b = {}
if len(set(a.keys())) == len(set(a.values())):
    for k, v in a.items():
        b[v] = k
    print(b)
else:
    print("error")
```

---

#### 📖 运行示例

**输入**：
```
{'x': 10, 'y': 20, 'z': 30}
```

**输出**：
```
{10: 'x', 20: 'y', 30: 'z'}
```

---

#### 📐 与上一版的对比

| 对比项 | `VEI3逆映射求解.py` | `VEI3逆映射求解2.py` |
| :--- | :--- | :--- |
| 遍历方式 | `for i in a.keys()` | `for k, v in a.items()` |
| 赋值方式 | `b[a[i]] = i` | `b[v] = k` |
| 可读性 | 较低（需通过键取两次值） | **较高**（直接解包键和值） |
| Pythonic 程度 | 较低 | **较高**（推荐） |
