# `VIE字符串字符统计.py` · 字符频率统计（列表去重版）

> **摘要**：遍历字符串，使用列表手动去重，然后统计每个字符出现的次数。这是一种基础但直观的统计方法，适合理解去重与计数的基本逻辑。

---

#### 💻 代码

```python
s = input()
w = []
s = s.lower()
for i in s:
    if i not in w:
        w.append(i)
    else:
        continue
w.sort()
for i in w:
    print(str(i) + '|' + str(s.count(i)), end=' ')
```

---

#### 📖 运行示例

**输入**：`Hello World`

**输出**：
```
 |3 d|1 e|1 h|1 l|3 o|2 r|1 w|1
```

（注意：空格也会被统计，显示为 ` |3`）

---

#### 📐 算法分析

| 步骤 | 说明 |
| :--- | :--- |
| 1. `s.lower()` | 转小写，统一大小写 |
| 2. 遍历去重 | 手动维护 `w` 列表，只保留首次出现的字符 |
| 3. 排序 | `w.sort()` 使输出按 ASCII/Unicode 顺序排列 |
| 4. 统计输出 | 用 `s.count(i)` 统计每个字符在原字符串中出现的次数 |

**时间复杂度**：$O(n^2)$（`not in w` 是 $O(n)$，嵌套遍历）；空间复杂度 $O(n)$。
