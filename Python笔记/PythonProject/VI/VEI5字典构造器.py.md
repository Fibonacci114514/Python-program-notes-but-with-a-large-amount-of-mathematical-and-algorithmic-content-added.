# `VEI5字典构造器.py` · 字典构造器（幂映射）

> **摘要**：使用 `for` 循环动态构造字典，将 0 到 10 映射到其自身的幂（$i^i$）。这是一种字典动态添加条目的典型示例。

---

#### 💻 代码

```python
from math import *

x = {}
for i in range(0, 11):
    x[i] = i ** i
print(x)
```

---

#### 📖 运行结果

```
{0: 1, 1: 1, 2: 4, 3: 27, 4: 256, 5: 3125, 6: 46656, 7: 823543, 8: 16777216, 9: 387420489, 10: 10000000000}
```

（注意：$0^0$ 在 Python 中定义为 1）

---

#### 📐 数学背景

$i^i$ 是指数运算的一种特殊形式，与**函数 $f(x) = x^x$** 相关。其导数和增长率在微积分中有特殊意义：
$$
\frac{d}{dx} x^x = x^x (\ln x + 1)
$$
