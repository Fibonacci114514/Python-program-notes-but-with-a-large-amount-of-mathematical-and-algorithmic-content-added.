# `VIE字符串字符统计[集合版].py` · 字符频率统计（集合去重版）

> **摘要**：利用集合自动去重的特性获取所有字符集合，然后统计每个字符的出现次数。相比列表手动去重，代码更简洁、更高效。

---

#### 💻 代码

```python
s = input()
w = list(set(s))
w.sort()
for i in w:
    print('{}|{:^5}'.format(i, s.count(i)), end=' ')
```

---

#### 📖 运行示例

**输入**：`Hello World`

**输出**：
```
 |3    d|1    e|1    h|1    l|3    o|2    r|1    w|1
```

---

#### 📐 算法分析

| 步骤 | 说明 |
| :--- | :--- |
| 1. `set(s)` | 自动去重，获取所有不同字符 |
| 2. `list(set(s))` | 转换为列表以便排序 |
| 3. `w.sort()` | 排序输出 |
| 4. 统计输出 | 用 `s.count(i)` 统计次数 |

**时间复杂度**：$O(n)$（集合构建）+ $O(k)$（统计，$k$ 为不同字符数）。

**相比列表版的改进**：
- 去重逻辑更简单（`set` 自动处理）
- 代码更短
- 效率更高（$O(n)$ vs $O(n^2)$）
