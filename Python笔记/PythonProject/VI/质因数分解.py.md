# `质因数分解.py` · 质因数分解（优化试除法）

> **摘要**：将正整数分解为质因数的乘积，并以幂次形式输出（如 $72 = 2^3 \times 3^2$）。使用优化的试除法：先处理因子 2，然后只检查奇数因子，且循环条件为 `divisor * divisor <= n`。

---

#### 💻 代码

```python
def prime_factors_optimized(n):
    factors = []
    # 处理偶数因子
    while n % 2 == 0:
        factors.append(2)
        n //= 2
    # 检查奇数因子
    divisor = 3
    while divisor * divisor <= n:
        while n % divisor == 0:
            factors.append(divisor)
            n //= divisor
        divisor += 2
    # 如果剩余的是质数
    if n > 2:
        factors.append(n)
    return factors

n = int(input())
f = prime_factors_optimized(n)
w = sorted(list(set(f)))
a = ['({}^{})'.format(i, f.count(i)) for i in w]
print('{}={}'.format(n, '×'.join(a)))
```

---

#### 📖 运行示例

**输入**：`72`

**输出**：
```
72=(2^3)×(3^2)
```

**输入**：`97`

**输出**：
```
97=(97^1)
```

---

#### 📐 算法原理

##### 算术基本定理
每个大于 1 的整数 $n$ 可以唯一分解为质数的乘积：
$$
n = p_1^{e_1} \times p_2^{e_2} \times \cdots \times p_k^{e_k}
$$

##### 算法优化
1. **预处理因子 2**：一次处理完所有 2 的因子，之后只检查奇数。
2. **循环上界**：`divisor * divisor <= n`，因为如果 $n$ 有大于 $\sqrt{n}$ 的因子，则必有小于 $\sqrt{n}$ 的因子。
3. **剩余质数**：循环结束后若 $n > 2$，则 $n$ 本身是一个质因子。

##### 时间复杂度
$O(\sqrt{n})$，远优于简单的 $O(n)$ 试除法。
