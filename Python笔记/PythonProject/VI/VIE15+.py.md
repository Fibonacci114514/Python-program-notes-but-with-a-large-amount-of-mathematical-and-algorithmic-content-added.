# `VIE15+.py` · 学生各科平均分计算

> **摘要**：字典存储了三个科目（语文 c、数学 m、英语 e）的成绩列表，计算并输出各科的平均分。

---

#### 💻 代码

```python
d = {"c": [85, 89, 76, 88], "m": [88, 92, 96], "e": [98, 90, 95]}

for k, v in d.items():
    s = sum(v)
    l = len(v)
    print('{}:{:.1f}'.format(k, s / l))
```

---

#### 📖 运行结果

```
c:84.5
m:92.0
e:94.3
```

---

#### 📐 代码拆解

| 变量 | 说明 |
| :--- | :--- |
| `k` | 科目名称（键） |
| `v` | 成绩列表（值） |
| `s = sum(v)` | 求和 |
| `l = len(v)` | 成绩个数 |
| `s / l` | 平均分 |

**知识点**：
- 字典的 `items()` 方法同时获取键和值
- `sum()` 和 `len()` 配合计算平均值
- `'{:.1f}'.format(...)` 保留 1 位小数
