# `test.py` · 浮点数精度测试

> **摘要**：这是一个极简的测试脚本，用于验证 `round()` 函数在特定小数位上的舍入行为。它揭示了浮点数在计算机中存储时不可避免的精度误差。

---

#### 💻 代码

```python
print(round(1.45, 1))
```

---

#### 📖 运行结果与解释

- **预期**：大多数情况下会输出 `1.4`（而非 `1.5`）。
- **原因**：`1.45` 在二进制浮点数中实际存储的值略小于 `1.45`，因此 `round` 按照“银行家舍入”（Banker's Rounding，即四舍六入五成双）或简单的四舍五入时，会得出 `1.4`。
- **扩展**：如需精确的十进制计算，应使用 `decimal.Decimal`。
