# `VE1九九乘法表.py` · 九九乘法表

> **摘要**：使用嵌套循环打印九九乘法表，并利用字符串格式化对齐输出，使其呈现规整的表格样式。

---

#### 💻 代码

```python
for i in range(1, 10):
    for j in range(1, i + 1):
        print('{:^10}'.format('{}×{}={}'.format(i, j, i * j)), end='|')
    print()
```

---

#### 📐 逻辑拆解

| 变量 | 作用 |
| :--- | :--- |
| `i`（外层循环） | 控制行号，从 1 到 9 |
| `j`（内层循环） | 控制列号，从 1 到 `i`（每行只打印到当前行号为止） |
| `'{:^10}'.format(...)` | 居中对齐，宽度 10 个字符 |
| `end='\|'` | 每项输出后以竖线分隔，不换行 |
| `print()` | 每行结束后换行 |
