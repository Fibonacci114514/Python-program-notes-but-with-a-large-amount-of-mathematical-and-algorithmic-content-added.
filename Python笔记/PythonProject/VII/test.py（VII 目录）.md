# test.py · 可变参数语法测试

> **摘要**：测试 Python 中可变参数 `*b` 的语法。`*b` 将传入的多个位置参数打包为一个元组。

---

#### 💻 代码

```python
def f(a, *b):
    pass

f(15, 5, 21, 46)
```

---

#### 📐 参数传递解析

```python
def f(a, *b):
    # a = 15
    # b = (5, 21, 46)
    pass
```

| 参数 | 含义 |
| :--- | :--- |
| `a` | 第一个位置参数（必须） |
| `*b` | 接收剩余所有位置参数，打包为元组 |
