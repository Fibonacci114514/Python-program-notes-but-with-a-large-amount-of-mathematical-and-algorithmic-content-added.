# 质因数分解.py（递归版） · 递归质因数分解

> **摘要**：递归实现质因数分解。`ifp(x)` 函数找到 $x$ 的最小质因子 $i$，返回 `[i, ifp(x//i)]`，形成嵌套列表结构，再由 `fac` 展平为质因数列表。

---

#### 💻 代码

```python
def ifp(x):
    for i in range(2, x):
        if x % i == 0:
            return [i, ifp(int(x / i))]
    else:
        return [x]

def fac(x):
    l = ifp(x)
    fac_list = []
    while len(l) == 2:
        fac_list.append(l[0])
        l = l[1]
    fac_list.append(l[0])
    return fac_list

n = int(input())
f = fac(n)
w = sorted(list(set(f)))
a = ['({}^{})'.format(i, f.count(i)) for i in w]
print('{}={}'.format(n, '×'.join(a)))
```

---

#### 📖 运行示例

**输入**：`72`

**输出**：
```
72=(2^3)×(3^2)
```

---

#### 📐 算法分析

##### 递归过程（$x=72$）
```
ifp(72) → i=2 → [2, ifp(36)]
ifp(36) → i=2 → [2, ifp(18)]
ifp(18) → i=2 → [2, ifp(9)]
ifp(9)  → i=3 → [3, ifp(3)]
ifp(3)  → else → [3]
```

**嵌套结构**：`[2, [2, [2, [3, [3]]]]]`

##### 展平过程
```
[2, [2, [2, [3, [3]]]]] → [2, 2, 2, 3, 3]
```

##### 特点
- **优点**：代码简洁，递归思想清晰
- **缺点**：递归深度受限；`ifp` 的循环效率较低（可优化到 $\sqrt{n}$）
