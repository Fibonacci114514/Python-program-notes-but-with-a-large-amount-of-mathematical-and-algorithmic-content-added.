# 词频分析程序(函数版).py · 模块化词频统计

> **摘要**：与集合版词频分析程序功能相同，但将数据处理流程拆分为两个独立函数：`gt`（数据清洗）和 `wb`（词频统计与排序）。这是函数式模块化设计的典型示例。

---

#### 💻 代码

```python
def gt(t):
    t = t.lower()
    s1 = set(t)
    s2 = set()
    for i in s1:
        if not (i.isdigit() or i.islower()):
            s2.add(i)
    for i in s2:
        t = t.replace(i, ' ')
    return t

def wb(t, n_top):
    w = t.split()
    c = {}
    for i in w:
        c[i] = c.get(i, 0) + 1
    e = {'the', 'and', 'to', 'of', 'a', 'be'}
    for i in e:
        if i in c:
            del c[i]
    x = list(c.items())
    x.sort(key=lambda x: x[1], reverse=True)
    return x[:n_top]

t = input()
t = gt(t)
for w, f in wb(t, 20):
    print('{:<20}{:>5}'.format(w, f))
print('HALT')
```

#### 📐 函数拆分设计

| 函数 | 输入 | 输出 | 功能 |
| :--- | :--- | :--- | :--- |
| `gt(t)` | 原始字符串 | 清洗后的字符串 | 转小写、移除标点 |
| `wb(t, n_top)` | 清洗后字符串 + Top N | 词频列表（前 N） | 分词、去停用词、统计、排序 |

##### 设计优势
1. **可复用性**：`gt` 和 `wb` 可分别在其他程序中调用
2. **可测试性**：每个函数可独立测试
3. **可维护性**：修改清洗规则只需修改 `gt`，修改统计逻辑只需修改 `wb`
4. **可读性**：主流程 `t = gt(t); wb(t, 20)` 清晰表达数据处理管道
