# ex.py · 斐波那契数列（记忆化优化版）

> **摘要**：使用 `functools.lru_cache` 装饰器对斐波那契数列进行记忆化优化，将时间复杂度从 $O(2^n)$ 降至 $O(n)$。这是**动态规划**中“自顶向下带备忘录”方法的典型实现。

---

#### 💻 代码

```python
from functools import lru_cache

@lru_cache(maxsize=None)
def fibo_opt(n):
    if n == 1 or n == 2:
        return 1
    return fibo_opt(n - 1) + fibo_opt(n - 2)

for i in range(1, 21):
    print(f"{fibo_opt(i):>8}", end="  " if i % 5 != 0 else "\n")
```

---

#### 📐 记忆化原理

##### 朴素递归的问题
```
f(5) → f(4) + f(3)
f(4) → f(3) + f(2)  ← f(3) 被重复计算
f(3) → f(2) + f(1)  ← f(2) 被重复计算
```

##### `lru_cache` 的作用
- 缓存函数每次调用的返回值
- 相同的输入直接从缓存读取，不再重复计算
- `maxsize=None` 表示缓存无上限

##### 复杂度对比
| 方法 | 时间复杂度 | 空间复杂度 |
| :--- | :--- | :--- |
| 朴素递归 | $O(2^n)$ | $O(n)$（递归栈） |
| 记忆化递归 | $O(n)$ | $O(n)$（缓存 + 栈） |
| 迭代（循环） | $O(n)$ | $O(1)$ |
