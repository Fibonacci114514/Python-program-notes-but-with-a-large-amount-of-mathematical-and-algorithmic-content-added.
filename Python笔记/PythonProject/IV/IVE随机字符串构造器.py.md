# `IVE随机字符串构造器.py` · 随机字符串生成器

> **摘要**：生成一个指定长度的随机字符串，字符从 `'A'` 到 `'z'` 的 ASCII 范围内随机选取。演示了 `random.randrange` 和 `chr()` 的配合使用。

---

#### 💻 代码

```python
from random import *
x = ''
n = int(input())
for i in range(n):
    x += chr(int(randrange(ord('A'), ord('z') + 1)))
print(x)
```

---

#### 📖 运行示例

**输入**：`10`

**输出**（每次运行结果不同）：
```
XyZqMpLkSa
```

---

#### 📐 字符范围

| 范围 | 起点 | 终点 |
| :--- | :--- | :--- |
| `ord('A')` | 65 | `'A'` |
| `ord('z')` | 122 | `'z'` |

`randrange(ord('A'), ord('z') + 1)` 从 `[65, 122]` 中随机选取整数，包含大写字母（65-90）、一些符号（91-96）和小写字母（97-122）。
