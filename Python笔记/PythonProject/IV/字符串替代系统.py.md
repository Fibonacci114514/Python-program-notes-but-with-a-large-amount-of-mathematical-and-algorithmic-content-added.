# `字符串替代系统.py` · 字符串重写系统（L-system 雏形）

> **摘要**：实现一个简单的字符串重写系统（Rewriting System），定义三条替换规则：`a → cb`，`b → bac`，`c → bb`。程序将输入的初始字符串按规则迭代多次，并格式化输出每次迭代后的字符串。这是 **形式语言**（Formal Language）和 **L-system** 的基础示例。

---

#### 💻 代码

```python
def Sprint(n, step, dx):
    if step + 1 % dx == 0:
        print('{:^20}'.format(n))
    else:
        print('{:^20}'.format(n), end="|")

def re(x):
    x = list(x)
    for i in range(len(x)):
        if x[i] == 'a':
            x[i] = 'cb'
        if x[i] == 'b':
            x[i] = 'bac'
        if x[i] == 'c':
            x[i] = 'bb'
    x = ''.join(x)
    return x

s_1 = input()
n = int(input())
for a in range(n):
    s_1 = re(s_1)
    Sprint(s_1, a, 10)
```

---

#### 📖 运行示例

**输入**：
```
a
5
```

**输出**（每行宽度 20，每 10 个换行）：
```
        cb         |
      bbbc         |
  bacbacbbbb       |
...
```

#### 📐 重写规则与形式语言

##### 规则表
| 原字符 | 替换为 |
| :--- | :--- |
| `a` | `cb` |
| `b` | `bac` |
| `c` | `bb` |

##### 迭代过程
```
第0轮: a
第1轮: cb
第2轮: bbbc
第3轮: bacbacbbbb
第4轮: cbbacbbbbcbbacbbbbbbacbbbb
...
```

#### 🧠 理论关联

##### 1. 形式语言（Formal Language）
字符串重写系统是**形式语言理论**（Chomsky Hierarchy）的核心概念。一个文法由一组产生式规则（如 `a → cb`）定义，可以生成一个语言。

##### 2. L-system（Lindenmayer system）
L-system 由生物学家 Aristid Lindenmayer 于 1968 年提出，用于模拟植物生长。本实验的字符串重写系统是 L-system 的简化版本：

- **并行替换**：每轮迭代同时替换所有字符（与代码中的 `for i in range(len(x))` 一致）
- **公理（Axiom）**：初始字符串（如 `"a"`）
- **规则**：本程序定义了一套固定的替换规则

##### 3. 计算理论
字符串重写系统是**图灵完备**的计算模型之一（如 Thue 系统、Markov 算法）。本实验虽然简单，但展示了重写系统的核心思想。

#### ⚠️ 代码潜在问题

`Sprint` 函数中的条件 `step + 1 % dx == 0` 因运算符优先级问题，实际为 `step + (1 % dx) == 0`，可能导致换行判断不准确。建议改为 `(step + 1) % dx == 0`：

```python
def Sprint(n, step, dx):
    if (step + 1) % dx == 0:
        print('{:^20}'.format(n))
    else:
        print('{:^20}'.format(n), end="|")
```
