# `IIIE15质数判定.py` · 输出 N 以内的所有质数

> **摘要**：该程序接收整数 `x`，输出 2 到 `x` 之间的所有质数。核心是利用 `for-else` 结构判断每个数是否为质数。

---

#### 💻 代码

```python
x = int(input())
for n in range(2, x + 1):
    for i in range(2, n):
        if n % i == 0:
            break
    else:
        print(n, end=",")
```

---

#### 📖 运行示例

**输入**：`20`

**输出**：
```
2,3,5,7,11,13,17,19,
```

---

#### 📐 算法分析

- **时间复杂度**：$O(n^2)$（朴素判断，有优化空间）
- **空间复杂度**：$O(1)$
- 关键技巧：`for-else` 结构，当 `for` 循环未执行 `break` 时执行 `else` 子句，即判定为质数。
