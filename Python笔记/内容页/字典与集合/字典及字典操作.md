> **摘要**:字典(dict)是 Python 中基于哈希表实现的键值对(key-value)映射结构,支持 $O(1)$ 时间复杂度的快速查找,插入和删除.字典的键必须为不可变类型,值可以是任意类型.本文系统介绍字典的创建,增删改查,遍历,排序与合并操作,并通过统计和映射示例展示其在算法与数据处理中的核心地位.
---

#### 1. 字典的定义与核心概念

字典是一种**映射(mapping)** 类型,将“键”(key)与“值”(value)关联起来.可以理解为数学中的函数 $f: K \to V$.

**核心特性**:
- **键值对**:`{键: 值, 键: 值, ...}`
- **键唯一**:字典中不允许出现相同的键,重复键会覆盖.
- **键不可变**:键必须是不可变类型(字符串,数字,元组),因为需要计算哈希值.
- **值任意**:值可以是任何 Python 对象(可变或不可变).
- **无序**(Python 3.7+ 按插入顺序保留):不能通过索引访问,只能通过键访问.

```python
# 示例:国家 → 国土面积(万平方公里)
dicAreas = {
    "俄罗斯": 1707.5,
    "加拿大": 997.1,
    "中国": 960.1,
    "美国": 936.4,
    "巴西": 854.7
}
```

#### 2. 字典的创建

##### 2.1 直接使用大括号 `{}`

```python
# 直接定义
d = {"name": "张三", "age": 20, "city": "北京"}

# 空字典
empty = {}
```

##### 2.2 使用 `dict()` 函数

```python
# 从关键字参数创建
d = dict(name="张三", age=20, city="北京")

# 从双元素序列列表创建
pairs = [("name", "张三"), ("age", 20), ("city", "北京")]
d = dict(pairs)

# 从 zip 对象创建(常用)
names = ["张三", "李四", "王五"]
scores = [85, 92, 78]
d = dict(zip(names, scores))   # {'张三': 85, '李四': 92, '王五': 78}
```

##### 2.3 字典推导式

```python
# 构建平方映射
squares = {x: x**2 for x in range(1, 6)}
print(squares)   # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}
```

#### 3. 字典的访问与操作

##### 3.1 访问值

```python
d = {"name": "张三", "age": 20}

# 方式一:直接访问(键不存在则报错 KeyError)
print(d["name"])      # 张三

# 方式二:get() 方法(推荐,可设默认值)
print(d.get("age"))          # 20
print(d.get("city"))         # None(不存在)
print(d.get("city", "未知"))  # 未知(指定默认值)
```

##### 3.2 添加与修改

赋值语句 `d[key] = value` 是一个**双重操作**:
- 若键**不存在** → 添加新条目
- 若键**已存在** → 修改对应值

```python
d = {"name": "张三", "age": 20}

# 添加新键
d["city"] = "北京"
print(d)   # {'name': '张三', 'age': 20, 'city': '北京'}

# 修改已有键
d["age"] = 21
print(d)   # {'name': '张三', 'age': 21, 'city': '北京'}
```

#### 4. 字典的删除操作

| 方式 | 语法 | 说明 |
|------|------|------|
| `del` 命令 | `del d[key]` | 删除指定键,键不存在则报错 |
| `pop()` | `d.pop(key, default)` | 删除并返回键对应的值,可设默认值避免报错 |
| `popitem()` | `d.popitem()` | 删除并返回最后一个插入的键值对(元组) |
| `clear()` | `d.clear()` | 清空所有条目,字典变为空字典 |
| `del d` | `del d` | 彻底删除字典对象 |

```python
d = {"name": "张三", "age": 20, "city": "北京"}

# del
del d["city"]          # 删除 city

# pop
age = d.pop("age")     # 返回 20,d 中移除 age

# popitem
item = d.popitem()     # 返回 ('name', '张三')

# clear
d.clear()              # {}

# 删除整个字典
del d                  # d 不再可用
```

#### 5. 字典的遍历

##### 5.1 遍历键值对(推荐)

```python
dicAreas = {"俄罗斯": 1707.5, "加拿大": 997.1, "中国": 960.1}

# 整体遍历条目
for item in dicAreas.items():
    print(item)   # ('俄罗斯', 1707.5)

# 解包遍历(推荐)
for country, area in dicAreas.items():
    print(f"{country}的面积是{area}万平方公里")
```

##### 5.2 遍历键

```python
for key in dicAreas.keys():
    print(key)

# 通过键访问值(不推荐直接,但可用)
for key in dicAreas.keys():
    print(key, dicAreas[key])
```

##### 5.3 遍历值

```python
for value in dicAreas.values():
    print(value)
```

> **注意**:`values()` 只能获取值,无法反向获取键,适合仅需数值的场景.

#### 6. 字典的排序

字典本身无序,但可用 `sorted()` 对键或条目进行排序,返回有序列表.

##### 6.1 按键排序

```python
dicAreas = {"俄罗斯": 1707.5, "加拿大": 997.1, "中国": 960.1}

# 按键升序
sorted_keys = sorted(dicAreas)
print(sorted_keys)   # ['中国', '俄罗斯', '加拿大']

for key in sorted_keys:
    print(key, dicAreas[key])
```

##### 6.2 按值排序(指定 `key`)

```python
# 按面积升序
sorted_items = sorted(dicAreas.items(), key=lambda x: x[1])
for country, area in sorted_items:
    print(country, area)   # 中国 960.1, 加拿大 997.1, 俄罗斯 1707.5

# 按面积降序
sorted_items = sorted(dicAreas.items(), key=lambda x: x[1], reverse=True)
```

#### 7. 字典的合并

##### 7.1 使用 `update()`(原地合并)

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

d1.update(d2)          # d1 被修改
print(d1)              # {'a': 1, 'b': 3, 'c': 4}(b 被覆盖)
print(d2)              # {'b': 3, 'c': 4}(d2 不变)
```

##### 7.2 使用 `dict()` 或 `**` 解包(返回新字典)

```python
d1 = {"a": 1, "b": 2}
d2 = {"b": 3, "c": 4}

# 使用 dict()
d3 = dict(d1, **d2)    # {'a': 1, 'b': 3, 'c': 4}

# 使用 `**` 解包(Python 3.5+)
d4 = {**d1, **d2}      # {'a': 1, 'b': 3, 'c': 4}
```

##### 7.3 使用 for 循环手动合并

```python
d1 = {"RU": 100, "CA": 997, "CHA": 960}
d2 = {"RU": 1707, "USA": 936, "BR": 854}

for key in d2:
    d1[key] = d2[key]   # 双重操作:添加或修改

print(d1)   # {'RU': 1707, 'CA': 997, 'CHA': 960, 'USA': 936, 'BR': 854}
```

#### 8. 综合应用示例

##### 8.1 字符频次统计

统计英文句子中每个字符出现的次数.

```python
sentence = "Life is short, we need Python."
counts = {}

for ch in sentence.lower():   # 统一小写
    # 方法一:使用 get
    counts[ch] = counts.get(ch, 0) + 1

    # 方法二:使用 if-else
    # if ch in counts:
    #     counts[ch] += 1
    # else:
    #     counts[ch] = 1

print(counts)
```

##### 8.2 字典合并保留两个键值(复杂合并)

将两个字典中相同键的值合并为元组或嵌套字典:

```python
areas = {"俄罗斯": 1707.5, "加拿大": 997.1, "中国": 960.1}
capitals = {"俄罗斯": "莫斯科", "加拿大": "渥太华", "中国": "北京", "美国": "华盛顿"}

# 合成为一个字典,值为 (面积, 首都)
merged = {}
for country in set(areas) | set(capitals):
    merged[country] = (areas.get(country), capitals.get(country))

print(merged)
# {'俄罗斯': (1707.5, '莫斯科'), '中国': (960.1, '北京'), '加拿大': (997.1, '渥太华'), '美国': (None, '华盛顿')}
```

#### 9. 与数学/算法的关联

| 数学概念 | Python 实现 | 算法应用 |
|----------|-------------|----------|
| 函数 $f: K \to V$ | 字典 | 查找表,映射关系 |
| 计数函数 | `dict.get(key, 0) + 1` | 词频统计,直方图 |
| 缓存(Memoization) | 字典缓存计算结果 | 动态规划优化 |
| 图邻接表 | `{顶点: [邻接顶点]}` | 图算法(BFS/DFS) |
| 集合覆盖 | 字典键值 | 贪心算法 |

---

#### 10. 注意事项与常见陷阱

| 陷阱 | 说明 |
|------|------|
| 键不存在时直接访问 `d[key]` | 会抛出 `KeyError`,应使用 `get()` |
| 键必须是不可变类型 | 列表不能作为键,元组可以 |
| 字典遍历时不能修改大小 | 如需修改,应先复制 `list(d.items())` |
| 可变对象作为值被意外修改 | 如果值是可变的(如列表),修改会影响原字典 |
| 字典合并时相同键会被覆盖 | 需注意合并顺序 |

#### 11. 快速参考

```python
# 创建
d = {"k1": "v1", "k2": "v2"}
d = dict(k1="v1", k2="v2")
d = dict(zip(keys, values))

# 访问
d[key]          # 可能报错
d.get(key, default)  # 安全访问

# 添加/修改
d[key] = value

# 删除
del d[key]
d.pop(key, default)
d.popitem()
d.clear()

# 遍历
for k, v in d.items(): ...
for k in d.keys(): ...
for v in d.values(): ...

# 判断
if key in d: ...

# 合并
d1.update(d2)        # 原地修改
d3 = {**d1, **d2}    # 新字典
d3 = dict(d1, **d2)  # 新字典

# 排序
sorted(d)                     # 键排序
sorted(d.items(), key=lambda x: x[1])   # 按值排序
```
