> **摘要**:本节通过一个最简单的数学问题——求两个整数的和与平均值,展示从问题分析到编写 Python 程序的完整过程,并说明 Python 的基本书写规则.这是理解“编程即数学表达”的第一步.

---

#### 1. 问题描述(数学建模)

> **给定两个整数,计算它们的和与平均值.**

- 输入:两个整数(记为 `m`, `n`)
- 输出:它们的和(`sum`)与平均值(`avg`)
- 数学关系:
  - $sum = m + n$
  - $\displaystyle avg = \frac{m + n}{2}$

这是一个最简单的“函数映射”问题:将输入空间(ℤ×ℤ)映射到输出空间(ℤ×ℝ).

---

#### 2. 算法设计(伪代码)

将数学公式转化为计算机执行的步骤:

```
1. 获取数据:从键盘输入两个整数 m 和 n
2. 计算处理:
   2.1 计算和:sum = m + n
   2.2 计算平均值:avg = (m + n) / 2
3. 输出结果:显示 sum 和 avg
```

这个算法体现了 **顺序结构**——从上到下依次执行,无分支或循环.

---

#### 3. Python 代码实现

```python
m = eval(input("输入第一个整数:"))
n = eval(input("输入第二个整数:"))

sum = m + n          # 求和
avg = (m + n) / 2    # 求平均

print("和为:", sum)
print("平均值为:", avg)
```

##### 3.1 代码逐行解析

| 代码 | 说明 |
|------|------|
| `m = eval(input(...))` | 获取键盘输入,`eval` 将字符串转为数值(这里为整数). |
| `sum = m + n` | 加法运算,符合数学中的“+”操作. |
| `avg = (m + n) / 2` | 除法 `/` 结果为浮点数,符合数学中的实数除法. |
| `print(...)` | 将结果输出到屏幕. |

> **注意**:`eval` 可以解析表达式(如输入 `3+5` 会得到 `8`),但存在安全风险(可能执行恶意代码).**建议初学阶段使用 `int(input(...))` 进行类型转换**,明确数据为整数.

#### 5. Python 书写规则(基石)

| 规则 | 说明 | 数学类比 |
|------|------|----------|
| 一行一条语句 | 通常每条语句占一行 | 如同数学公式分步书写 |
| 行首无空格(除缩进) | 顶层代码顶格写,缩进用于代码块(后续学习) | 保持结构清晰 |
| `#` 注释 | 注释仅用于说明,不执行 | 相当于数学中的旁注 |
| 英文符号 | 所有运算符,标点必须英文半角 | 不要与中文标点混淆 |
| 缩进表示代码块 | 将在分支,循环,函数中体现(第三章) | 体现逻辑层次 |

#### 6. 与数学/算法的关联

- **变量**:`m`, `n`, `sum`, `avg` 如同数学符号,代表数值.
- **表达式**:`m + n` 和 `(m+n)/2` 是代数表达式的直接翻译.
- **数据类型**:`int`(整数)和 `float`(浮点数)对应数学中的整数和实数.
- **算法思想**:顺序执行是任何算法的基本控制结构之一.
