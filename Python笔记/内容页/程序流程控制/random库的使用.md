> **摘要**:`random` 是 Python 内置的伪随机数生成库,提供多种分布随机数生成函数.本文系统介绍常用函数及其在数学模拟,概率统计,算法随机化中的应用,并强调随机种子设置的重要性,确保实验结果可复现.

---
#### 1. 导入方式

```python
from random import *      # 常用,直接调用函数名
# 或
import random             # 需要加 random. 前缀
```

> 注意:伪随机数基于确定性算法,并非真正的随机.通过设置种子(`seed`)可使序列可复现.

---

#### 2. 常用函数一览

| 函数 | 参数 | 返回值 | 数学形式 |
|------|------|--------|----------|
| `random()` | 无 | $[0.0, 1.0)$ 之间的浮点数 | 均匀分布 U(0,1) |
| `randrange(n)` | 整数 | $[0, n-1]$ 整数 | 均匀整数 |
| `randrange(m, n)` | 整数 | $[m, n-1]$ 整数 | 均匀整数 |
| `randrange(m, n, d)` | 整数 | 步长 d 的等差数列中随机选一个 | 均匀整数 |
| `randint(m, n)` | 整数 | $[m, n]$ 整数(等价于 `randrange(m, n+1)`) | 均匀整数 |
| `uniform(m, n)` | 浮点数 | $[m, n]$ 浮点数 | 连续均匀分布 |
| `choice(s)` | 序列 | 序列中随机一个元素 | 离散均匀 |
| `sample(s, k)` | 序列, 整数 k | 从序列中随机选 k 个不重复元素(列表) | 无放回抽样 |
| `shuffle(s)` | 序列 | 原地打乱序列,返回 `None` | 随机排列 |
| `seed(n)` | 整数(可选) | 设置随机种子,`seed()` 用系统时间初始化 | 确定随机序列起点 |

---

#### 3. 常用示例

##### 3.1 生成随机数

```python
from random import *

# 生成 [0,1) 浮点数
r = random()          # 0.374...

# 生成 1~10 的整数
num = randint(1, 10)

# 生成 0~100 中的偶数
even = randrange(0, 101, 2)

# 生成 [3.14, 6.28) 浮点数
x = uniform(3.14, 6.28)
```

##### 3.2 随机选择与抽样

```python
fruits = ['apple', 'banana', 'orange', 'grape']

# 随机选一个
pick = choice(fruits)

# 随机选两个(不重复)
two = sample(fruits, 2)

# 打乱顺序
shuffle(fruits)
print(fruits)   # 顺序被随机打乱
```

##### 3.3 设置种子(可复现)

```python
seed(42)
print(random())   # 0.6394267984578837
print(random())   # 0.025010755222666936

# 重新设置相同种子,序列重现
seed(42)
print(random())   # 0.6394267984578837   # 与上次一致
```

> **用途**:在调试,测试,论文实验时保证结果可复现.

#### 4. 与数学/算法的关联

##### 4.1 蒙特卡洛模拟(概率统计)

用随机数模拟物理过程或统计实验,通过大量重复实验估计概率或数值.

**示例:估算圆周率 π**

```python
from random import random

n = 1000000
inside = 0
for _ in range(n):
    x, y = random(), random()
    if x*x + y*y <= 1.0:
        inside += 1

pi_estimate = 4 * inside / n
print(pi_estimate)   # 约 3.141...
```

> 原理:单位圆面积与正方形面积之比 = π/4.

##### 4.2 概率分布模拟

- 均匀分布:`random()`, `uniform()`
- 二项分布:可组合 `random()` 与循环模拟
- 正态分布:`random.gauss(mu, sigma)`(需额外导入)

##### 4.3 算法随机化

- 随机快速排序:随机选择基准元素
- 随机化算法(如蒙特卡洛树搜索)
- 抽样算法(如 Reservoir Sampling)

---

#### 5. 注意事项

| 问题 | 说明 |
|------|------|
| 伪随机性 | `random` 是伪随机,不适用于加密安全场景(需用 `secrets` 模块) |
| 种子设置 | 不同种子产生不同序列;相同种子保证可复现 |
| 性能 | `random()` 效率高,适合大规模模拟 |
| 分布扩展 | 需要正态分布,指数分布等,可使用 `random.gauss()`, `random.expovariate()` |

---

#### 6. 扩展:其他分布函数(`random` 模块中的额外函数)

| 函数 | 分布 |
|------|------|
| `gauss(mu, sigma)` | 正态分布(高斯分布) |
| `expovariate(lambd)` | 指数分布 |
| `betavariate(alpha, beta)` | Beta 分布 |
| `triangular(low, high, mode)` | 三角分布 |

> **总结**:`random` 库是概率统计模拟,算法随机化,游戏开发等场景的基础工具.掌握随机数的生成与种子管理,你就能将概率论知识转化为可运行的实验,验证数学直觉并探索随机现象.在后续机器学习(如随机森林,神经网络权重初始化)中,随机数也是不可或缺的工具.
