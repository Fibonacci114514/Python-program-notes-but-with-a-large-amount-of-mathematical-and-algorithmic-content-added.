> **摘要**:循环结构让程序能够重复执行特定代码块,是解决数列求和,迭代逼近,枚举搜索等问题的核心工具.本文系统讲解 `for` 和 `while` 两种循环,以及 `break`,`continue`,`else` 子句和循环嵌套的使用方法,并通过典型数学问题展示循环在算法实现中的核心地位.

---

#### 1. 何时需要循环

当需要**重复执行**某些有规律的操作时,应使用循环.典型场景:

| 场景 | 示例 |
|------|------|
| 累加求和 | 计算 $1+2+\cdots+100$ |
| 数列生成 | 斐波那契数列前 $n$ 项 |
| 枚举搜索 | 找出所有满足条件的三位数 |
| 迭代逼近 | 牛顿法求平方根 |
| 遍历数据 | 逐个处理字符串/列表中的元素 |

---

#### 2. `for` 循环 —— 确定性迭代

`for` 循环用于遍历已知的迭代对象(如字符串,`range()`,列表等).

```python
for 变量 in 迭代器:
    语句块
```

##### 2.1 遍历字符串

```python
for ch in "abcde":
    print(ch, end="  ")   # a  b  c  d  e
```

**统计大小写字母与数字个数**

```python
s = input("请输入一句英文:")
upper = lower = digit = 0
for ch in s:
    if ch.isupper(): upper += 1
    elif ch.islower(): lower += 1
    elif ch.isdigit(): digit += 1
print(f"大写:{upper},小写:{lower},数字:{digit}")
```

##### 2.2 `range()` 函数生成数值序列

| 调用方式 | 生成序列 | 示例 `range(1, 10, 2)` → 1,3,5,7,9 |
|----------|----------|--------------------------------------|
| `range(n)` | 0, 1, 2, …, n-1 | |
| `range(m, n)` | m, m+1, …, n-1 | |
| `range(m, n, d)` | m, m+d, m+2d, …(不超过 n) | |

**示例:1 到 100 求和**

```python
total = 0
for i in range(1, 101):
    total += i
print(total)   # 5050
```

**求 1~100 奇数和与偶数和**

```python
odd_sum = even_sum = 0
for i in range(1, 101):
    if i % 2 == 0:
        even_sum += i
    else:
        odd_sum += i
```

#### 3. `while` 循环 —— 条件迭代

适用于循环次数不确定,但有明确终止条件的场景.

```python
while 条件表达式:
    语句块
```

- 每次循环前检查条件,为 `True` 则执行,否则退出.
- 需在循环体内**修改条件相关变量**,否则可能死循环.

**示例:1 到 100 求和(while 版)**

```python
total = 0
i = 1
while i <= 100:
    total += i
    i += 1
print(total)
```

**示例:牛顿迭代法求平方根**

```python
def sqrt_newton(a, eps=1e-6):
    x = a / 2
    while abs(x * x - a) > eps:
        x = (x + a / x) / 2
    return x
```

**示例:读入序列直到输入 -1**

```python
nums = []
x = float(input("输入数字(-1结束):"))
while x != -1:
    nums.append(x)
    x = float(input("输入数字(-1结束):"))
print(f"已输入 {len(nums)} 个数")
```

#### 4. 循环控制:`break` 与 `continue`

| 语句 | 作用 |
|------|------|
| `break` | 立即终止整个循环,跳到循环之后 |
| `continue` | 跳过本轮剩余语句,直接进入下一轮循环 |

**示例:判断素数(使用 break)**

```python
n = int(input("输入 n (n>2):"))
for i in range(2, n):
    if n % i == 0:
        print(n, "不是素数")
        break
else:
    print(n, "是素数")
```

---

#### 5. `for-else` / `while-else` 子句

- 循环**正常结束**(未执行 `break`)时执行 `else` 子句.
- 常用于“未找到”场景.

**示例:素数判断(else 版)**

```python
for i in range(2, int(n**0.5) + 1):
    if n % i == 0:
        print("合数")
        break
else:
    print("素数")
```

---

#### 6. 循环嵌套

循环内部可以包含另一层循环,用于处理二维问题.

**示例:打印三角形星号**

```python
for i in range(1, 6):
    for j in range(i):
        print("*", end="")
    print()
```

**示例:输出 300 以内所有素数**

```python
for n in range(2, 301):
    is_prime = True
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            is_prime = False
            break
    if is_prime:
        print(n, end=" ")
```

#### 7. 与数学/算法的关联

| 数学问题 | 对应的循环结构 |
|----------|----------------|
| 数列求和 $\sum_{i=1}^{n} a_i$ | `for` 循环累加 |
| 级数逼近(泰勒展开) | `while` 按精度迭代 |
| 欧几里得算法(GCD) | `while` 循环取余 |
| 枚举质数 | 双重 `for` 循环(外层遍历,内层判断) |
| 蒙特卡洛模拟 | `for` 循环大量重复实验 |
| 矩阵遍历 | 双重 `for` 循环(行,列) |
| 图搜索(BFS/DFS) | 循环 + 队列/栈(数据结构) |

---

#### 8. 常见陷阱与建议

| 问题 | 建议 |
|------|------|
| 死循环 | 确保 `while` 条件会在循环体内发生变化 |
| 循环变量被意外修改 | 不要在循环体内修改 `for` 的迭代变量 |
| 嵌套过深 | 若嵌套 > 3 层,考虑拆分为函数 |
| 性能问题 | Python 循环较慢,可考虑用向量化库(NumPy)替代 |

---

> **总结**:循环是算法实现的核心,几乎所有的迭代算法都离不开它.`for` 适合已知次数的遍历,`while` 适合条件驱动的迭代.掌握循环控制,嵌套和 `else` 子句,你就能实现从简单累加到复杂模拟的各种算法.
