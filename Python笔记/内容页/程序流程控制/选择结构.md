> **摘要**:选择结构(分支结构)让程序根据条件执行不同的代码路径.本文系统讲解 `if` 单分支,`if-else` 双分支,`if-elif-else` 多分支,以及嵌套分支的语法和应用场景,并通过多个数学/算法示例展示分支结构在问题求解中的核心作用.

---
#### 1. 为何需要分支结构

程序遇到需要根据不同情况做不同处理时,就需要分支结构.

> **典型案例**:输入三角形三边,若合法则计算面积,否则提示错误.

```python
import math
a = float(input("请输入三角形的边长a:"))
b = float(input("请输入三角形的边长b:"))
c = float(input("请输入三角形的边长c:"))
h = (a+b+c)/2
area = math.sqrt(h*(h-a)*(h-b)*(h-c))
print(f"三角形的面积为:{area:.2f}")
```

若输入 `a=1, b=1, c=10`,则 `h*(h-a)*(h-b)*(h-c)` 为负,`math.sqrt` 报错.因此需要加入合法性检查.

---

#### 2. 单分支结构:`if` 语句

```python
if 条件表达式:
    语句块
```

- 条件表达式后**必须有冒号** `:`
- 语句块需**缩进**(通常 4 个空格)

```python
# 保证 a > b
if a < b:
    a, b = b, a
```

---

#### 3. 双分支结构:`if-else` 语句

```python
if 条件表达式:
    语句块1
else:
    语句块2
```

- 两者**有且只有一个**会被执行.

**示例:判断回文串**

```python
s = input("请输入字符串:")
if s == s[::-1]:
    print(s + "为回文串")
else:
    print(s + "不是回文串")
```

**示例:三角形面积(带合法性检查)**

```python
if (a+b>c) and (a+c>b) and (b+c>a) and (a>0) and (b>0) and (c>0):
    h = (a+b+c)/2
    area = math.sqrt(h*(h-a)*(h-b)*(h-c))
    print(f"面积为:{area:.2f}")
else:
    print("用户输入数据有误！")
```

##### 3.1 简洁表达式(三元表达式)

```python
# 求绝对值
x = int(input("x="))
print(x) if x >= 0 else print(-x)
```

语法:`表达式1 if 条件 else 表达式2`,适合简单分支赋值.

#### 4. 多分支结构:`if-elif-else` 语句

```python
if 条件表达式1:
    语句块1
elif 条件表达式2:
    语句块2
elif 条件表达式3:
    语句块3
# ... 可以有多个 elif
else:
    语句块n   # else 可选
```

- 从上到下依次判断,遇到第一个 `True` 则执行对应块并跳出.
- `else` 可以省略,表示其他情况不处理.

**示例:BMI 分类**

```python
height = float(input("请输入身高(米):"))
weight = float(input("请输入体重(千克):"))
bmi = weight / height ** 2
print(f"您的BMI指数是:{bmi:.1f}")

if bmi < 18.5:
    print("偏瘦")
elif bmi < 24:
    print("正常")
elif bmi < 28:
    print("偏胖")
elif bmi < 32:
    print("肥胖")
else:
    print("重度肥胖")
```

#### 5. 嵌套分支

分支结构内部可以再包含分支,称为嵌套.

**示例:求三位数各位中的最大值**

```python
num = int(input("请输入一个三位正整数:"))
a = num // 100
b = num // 10 % 10
c = num % 10

# 方法1:嵌套 if
if a > b:
    if a > c:
        max_num = a
    else:
        max_num = c
else:
    if b > c:
        max_num = b
    else:
        max_num = c

print(f"{num}中最大的数字是:{max_num}")

# 方法2:多分支(更简洁)
if a > b and a > c:
    max_num = a
elif b > a and b > c:
    max_num = b
else:
    max_num = c

# 方法3:使用内置函数(最简洁)
max_num = max(a, b, c)
```

> **经验**:遇到同一问题的多种解法时,优先选择**清晰,易读**的代码,便于后期维护.

#### 6. 与数学/算法的关联

| 应用场景 | 分支逻辑 |
|----------|----------|
| 分段函数 | 根据自变量区间选择不同表达式 |
| 条件判断 | 判断数奇偶,素数,三角形类型 |
| 算法决策 | 搜索,排序,游戏中的状态转换 |
| 边界条件 | 处理输入为 0,负值,越界等特殊情况 |
| 错误处理 | 检查数据合法性(如除数不为零) |

---

#### 7. 注意事项

- **冒号不可省略**:`if`, `elif`, `else` 后都需要 `:`
- **缩进一致**:同一代码块缩进量必须相同(通常 4 空格)
- **`else` 不含条件**:与 `elif` 不同,`else` 后面不跟条件表达式
- **避免过深嵌套**:超过 3 层可考虑拆分逻辑或使用函数

---

> **总结**:选择结构让程序具备“判断能力”.`if` 分支是算法中决策节点的直接体现,掌握其用法是编写有逻辑的程序的基础.在多分支中,顺序和条件的设计直接影响程序正确性,需要仔细推敲.
