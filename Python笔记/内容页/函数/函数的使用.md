> **摘要**:掌握函数的调用方式,理解位置参数,默认值参数,关键字参数和可变参数的用法,是函数编写和使用的进阶技能.本文系统讲解函数调用时参数的多种传递方式,以及如何返回多个值,帮助读者灵活,高效地使用函数.

---

#### 1. 函数调用的基本规则

调用语法:`函数名([实参列表])`

**规则**:
1. 实参与形参**按位置一一对应**(位置参数).
2. 有返回值的函数可出现在表达式中;无返回值的函数只能单独调用.
3. 实参数量必须与形参数量匹配(除非有默认参数).

```python
def greet(name):
    print(f"Hello, {name}!")

def add(a, b):
    return a + b

# 无返回值 → 单独调用
greet("张三")          # Hello, 张三!

# 有返回值 → 可用于表达式
result = add(3, 5)     # 8
print(add(10, 20))     # 30
```

---

#### 2. 位置参数(默认方式)

实参按**定义顺序**传递给形参,是最常用的传递方式.

```python
def info(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

info("张三", 20, "北京")   # 顺序必须一致
```

---

#### 3. 默认值参数(可选参数)

在定义函数时,可为参数指定**默认值**,调用时可省略对应实参.默认参数必须放在形参列表的最右侧.

```python
def calculate(score, weight=0.6):
    return score * weight

print(calculate(90))        # 54.0(使用默认 weight=0.6)
print(calculate(90, 0.8))   # 72.0(覆盖默认值)
```

**典型应用**:加权计算,配置参数.

```python
def calc_grade(midterm, final, mid_weight=0.4):
    return midterm * mid_weight + final * (1 - mid_weight)

print(calc_grade(80, 90))           # 86.0(权重 0.4)
print(calc_grade(80, 90, 0.3))      # 87.0(权重 0.3)
```

---

#### 4. 关键字参数(名称传递)

调用时通过 **形参名 = 实参** 的方式指定参数,优点:
- 明确参数含义.
- 与顺序无关.
- 可选择性传递.

```python
def info(name, age, city):
    print(f"{name}, {age}岁, 来自{city}")

# 正常位置调用
info("张三", 20, "北京")

# 关键字调用(顺序可变)
info(city="上海", name="李四", age=22)
```

**与默认值结合**:

```python
def calc_grade(midterm, final, mid_weight=0.4):
    return midterm * mid_weight + final * (1 - mid_weight)

# 只指定可选参数
print(calc_grade(80, 90, mid_weight=0.3))
```

---

#### 5. 返回多个值

函数可通过 `return` 返回多个值,实际上返回的是一个**元组**,可利用解包赋值接收.

```python
def divmod_example(a, b):
    return a // b, a % b   # 返回商和余数

quotient, remainder = divmod_example(10, 3)
print(quotient, remainder)   # 3 1
```

#### 6. 可变长参数:`*args` 和 `**kwargs`

用于处理**不确定数量**的参数.

##### 6.1 `*args`:接收多个位置参数(打包为元组)

```python
def sum_all(*args):
    return sum(args)

print(sum_all(1, 2, 3, 4, 5))   # 15
print(sum_all(10, 20))          # 30
```

##### 6.2 `**kwargs`:接收多个关键字参数(打包为字典)

```python
def show_info(**kwargs):
    for key, value in kwargs.items():
        print(f"{key}: {value}")

show_info(name="张三", age=20, city="北京")
# name: 张三
# age: 20
# city: 北京
```

##### 6.3 组合使用

```python
def func(x, y, *args, **kwargs):
    print(f"x={x}, y={y}")
    print(f"args: {args}")
    print(f"kwargs: {kwargs}")

func(1, 2, 3, 4, 5, a=10, b=20)
# x=1, y=2
# args: (3, 4, 5)
# kwargs: {'a': 10, 'b': 20}
```

---

#### 7. 参数传递方式总结

| 方式 | 语法 | 说明 |
|------|------|------|
| 位置参数 | `func(a, b)` | 按顺序传递 |
| 默认值参数 | `def func(a, b=10)` | 可省略的形参 |
| 关键字参数 | `func(a=1, b=2)` | 按名称传递,顺序无关 |
| 可变位置参数 | `*args` | 接收多个位置参数 |
| 可变关键字参数 | `**kwargs` | 接收多个关键字参数 |

---

#### 8. 常见调用陷阱

| 问题 | 说明 |
|------|------|
| 参数顺序错误 | 位置参数必须在关键字参数之前 |
| 默认参数在非默认前 | 定义时默认参数必须放在右侧 |
| 可变参数后仍有参数 | 可变参数之后只能跟关键字参数 |
| 默认参数为可变对象 | 默认参数是 `[]` 或 `{}` 时会共享状态,建议使用 `None` |

```python
# 默认参数陷阱示例
def append_to_list(item, lst=[]):   # 危险！
    lst.append(item)
    return lst

print(append_to_list(1))   # [1]
print(append_to_list(2))   # [1, 2]  ← 共享同一个列表！

# 正确做法
def append_to_list(item, lst=None):
    if lst is None:
        lst = []
    lst.append(item)
    return lst
```

---

> **总结**:函数的参数传递方式是 Python 灵活性的体现.位置参数提供直观的调用方式,默认参数增加了函数的适应性,关键字参数提高了可读性,而可变参数则让函数可以处理任意数量的输入.合理组合这些参数类型,可写出既灵活又清晰的函数接口.
