# 二分排序.py · 递归最大值提取排序

> **摘要**：递归实现的排序算法。每次从列表中取出最大值，递归处理剩余部分，最终通过嵌套列表展平得到有序序列。这是一种“最大值冒泡”的递归版本。

---

#### 💻 代码

```python
def r1(list_1):
    m = max(list_1)
    list_1.remove(m)
    if len(list_1) > 1:
        return [m, r1(list_1)]
    else:
        return [m, list_1]

def r(x, rev=False):
    l = r1(x)
    fac_list = []
    while len(l) == 2:
        fac_list.append(l[0])
        l = l[1]
    fac_list.append(l[0])
    if not rev:
        fac_list = fac_list[::-1]
    return fac_list

print(r(eval(input())))
```

---

#### 📖 运行示例

**输入**：
```
[3, 1, 4, 1, 5, 9, 2, 6]
```

**输出**：
```
[1, 1, 2, 3, 4, 5, 6, 9]
```

---

#### 📐 算法分析

##### `r1` 的递归结构
以 `[3, 1, 4, 2]` 为例：
```
r1([3, 1, 4, 2])
→ [4, r1([3, 1, 2])]
→ [4, [3, r1([1, 2])]]
→ [4, [3, [2, [1]]]]
→ 展开后: [4, 3, 2, 1]（降序）
```

##### 展平过程
`r` 函数通过 `while len(l) == 2` 将嵌套列表展平：
```
[4, [3, [2, [1]]]] → [4, 3, 2, 1]
```

##### 排序方向
- `rev=False`（默认）：升序输出（翻转降序列表）
- `rev=True`：降序输出

##### 时间复杂度
- 每次调用 `max()` 和 `remove()` 均为 $O(n)$
- 递归深度 $n$，总复杂度 $O(n^2)$
