# 自然数形式定义.py · 冯·诺依曼序数构造

> **摘要**：基于集合论（冯·诺依曼序数）递归构造自然数。每个自然数被定义为前一个自然数的**后继**：$n+1 = n \cup \{n\}$。这是**计算理论**与**数学基础**的编程体现。

---

#### 💻 代码

```python
def N(n):
    if n <= 0:
        return ["∅"]
    else:
        return N(n - 1) + [N(n - 1)]

print(N(0)[-1])
```

---

#### 📖 运行示例

**输入**：`N(0)[-1]`

**输出**：
```
∅
```

**修改为**：`print(N(2))` 可查看更深的构造：

```
['∅', ['∅'], ['∅', ['∅']]]
```

---

#### 📐 数学背景：冯·诺依曼序数

在集合论中，自然数可以用空集 $\varnothing$ 递归地定义：
$$
\begin{aligned}
0 &= \varnothing = \{\} \\
1 &= \{0\} = \{\varnothing\} \\
2 &= \{0, 1\} = \{\varnothing, \{\varnothing\}\} \\
3 &= \{0, 1, 2\} = \{\varnothing, \{\varnothing\}, \{\varnothing, \{\varnothing\}\}\}
\end{aligned}
$$

##### 代码对应
```python
N(0) = ["∅"]                                    # 0 = {∅}
N(1) = N(0) + [N(0)] = ["∅", ["∅"]]            # 1 = {0, ∅}
N(2) = N(1) + [N(1)] = ["∅", ["∅"], ["∅", ["∅"]]]  # 2 = {0, 1}
```

##### 理论基础
- **冯·诺依曼序数**是集合论中自然数的标准构造
- 每个自然数都是**传递集**（Transitive Set）
- 自然数的序关系由集合的**包含关系**定义
