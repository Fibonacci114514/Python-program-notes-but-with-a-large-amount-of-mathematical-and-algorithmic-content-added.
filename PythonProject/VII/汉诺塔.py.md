# 汉诺塔.py · 汉诺塔递归求解（带步骤编号）

> **摘要**：经典的汉诺塔（Tower of Hanoi）问题递归实现。通过两个函数 `m`（移动记录）和 `h`（递归核心），输出每一步的移动序列，并用全局变量 `i` 为每一步编号。

---

#### 💻 代码

```python
i = 1

def m(n, mf, mt):
    global i
    print(i, n, mf, '->', mt)
    i += 1

def h(n, A, B, C):
    if n == 1:
        m(1, A, C)
    else:
        h(n - 1, A, C, B)
        m(n, A, C)
        h(n - 1, B, A, C)

print(h(2, 'x', 'y', 'z'))
```

---

#### 📖 运行示例

**输入**：`h(2, 'x', 'y', 'z')` 的输出：

```
1 1 x -> y
2 2 x -> z
3 1 y -> z
None
```

`None` 是 `h(2)` 无返回值时 `print()` 的默认输出。

---

#### 📐 算法原理

汉诺塔问题的核心递归思路：
1. 将 $n-1$ 个盘子从 A 移到 B（借助 C）
2. 将第 $n$ 个盘子从 A 移到 C
3. 将 $n-1$ 个盘子从 B 移到 C（借助 A）

##### 执行过程（$n=2$）
```
① h(2, x, y, z)
   ├── ② h(1, x, z, y) → 移动 1: x → y
   ├── ③ m(2, x, z)    → 移动 2: x → z
   └── ④ h(1, y, x, z) → 移动 3: y → z
```

##### 全局变量 `i`
用于计数移动步数，每次移动后自增。对于 $n$ 个盘子，总步数为 $2^n - 1$。
