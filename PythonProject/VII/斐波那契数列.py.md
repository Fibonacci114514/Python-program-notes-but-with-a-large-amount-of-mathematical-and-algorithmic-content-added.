# 斐波那契数列.py · 递归生成斐波那契数列

> **摘要**：使用递归生成斐波那契数列前 40 项，并利用 `Sprint` 函数格式化输出，每行 4 项。

---

#### 💻 代码

```python
def Sprint(n, step, dx):
    if step % dx == 0:
        print('{:^20}'.format(n))
    else:
        print('{:^20}'.format(n), end="|")

def f(n):
    if n <= 1:
        return n
    else:
        return f(n - 1) + f(n - 2)

for i in range(40):
    Sprint(f(i), i + 1, 4)
```


#### 📐 算法分析

##### 递归定义
$$
F(n) = \begin{cases}
0, & n = 0 \\
1, & n = 1 \\
F(n-1) + F(n-2), & n > 1
\end{cases}
$$

##### 时间复杂度
- **朴素递归**：$O(2^n)$（大量重复计算）
- **优化方法**：记忆化（`@lru_cache`）或迭代

##### 性能瓶颈
`f(40)` 在朴素递归下会执行约 $2^{40}$ 次调用，非常耗时。建议使用 `ex.py` 中的记忆化版本。
