# 质数判定模块.py · 数论三连：质数判定、孪生素数、哥德巴赫猜想

> **摘要**：一个完整的数论实验模块，包含三个子任务：① 1000 以内所有质数输出；② 孪生素数（相差 2 的质数对）输出；③ 哥德巴赫猜想在 1000 以内的验证。

---

#### 💻 代码

```python
def ifp(x):
    for i in range(2, x):
        if x % i == 0:
            return False
    return True

# ① 输出 1000 以内所有质数
for m in range(2, 1000):
    if ifp(m):
        print(m)

# ② 孪生素数猜想
for m in range(2, 1000):
    if ifp(m) and ifp(m + 2):
        print(m, m + 2)

# ③ 哥德巴赫猜想验证
for m in range(2, 1000, 2):
    for n in range(2, m - 1):
        if ifp(n) and ifp(m - n):
            print('{:^5}+{:^5}={:^5}'.format(n, m - n, m))
            break
```

#### 📐 数学背景

##### 1. 质数判定（朴素算法）
对每个 $n$，检查从 2 到 $n-1$ 的所有数是否能整除 $n$。效率 $O(n)$，可优化为 $O(\sqrt{n})$（检查到 $\sqrt{n}$ 即可）。

##### 2. 孪生素数猜想
孪生素数是指相差为 2 的两个质数对（如 3 和 5、11 和 13）。孪生素数猜想断言存在无穷多对孪生素数，但尚未被证明。

##### 3. 哥德巴赫猜想
每个大于 2 的偶数都可以表示为两个质数之和。该猜想由德国数学家哥德巴赫于 1742 年提出，至今未被证明或证伪。该程序在 1000 以内验证了其成立。
