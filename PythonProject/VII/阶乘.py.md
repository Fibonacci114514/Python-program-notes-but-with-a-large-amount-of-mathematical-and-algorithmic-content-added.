# 阶乘.py · 递归计算阶乘

> **摘要**：经典递归示例——计算 $n!$。递归定义：$n! = n \times (n-1)!$，终止条件：$0! = 1$。

---

#### 💻 代码

```python
def f(n):
    if n == 0:
        return 1
    else:
        return n * f(n - 1)

print(f(25))
```

---

#### 📖 运行结果

```
15511210043330985984000000
```

即 $25! = 15511210043330985984000000$。

---

#### 📐 数学背景

阶乘的递归定义：
$$
n! = \begin{cases}
1, & n = 0 \\
n \times (n-1)!, & n > 0
\end{cases}
$$

##### 执行过程（$f(5)$）
```
f(5) = 5 × f(4)
     = 5 × 4 × f(3)
     = 5 × 4 × 3 × f(2)
     = 5 × 4 × 3 × 2 × f(1)
     = 5 × 4 × 3 × 2 × 1 × f(0)
     = 5 × 4 × 3 × 2 × 1 × 1
     = 120
```
