# 等差数列求和模块.py · 等差数列求和

> **摘要**：计算从 `n_start` 到 `n_end` 的整数累加和（等差为 1）。这是循环累加的典型示例，也可以使用高斯求和公式 $\displaystyle S = \frac{(a_1 + a_n) \times n}{2}$ 直接计算。

---

#### 💻 代码

```python
def s(n_start, n_end):
    x = 0
    for i in range(n_start, n_end + 1):
        x += i
    return x

print(s(0, 100))
```

---

#### 📖 运行结果

```
5050
```

即 $0 + 1 + 2 + \cdots + 100 = 5050$。

---

#### 📐 算法对比

| 方法 | 代码 | 时间复杂度 |
| :--- | :--- | :--- |
| 循环累加 | `for i in range(n_start, n_end + 1): x += i` | $O(n)$ |
| 高斯求和 | `(n_start + n_end) * (n_end - n_start + 1) // 2` | $O(1)$ |
