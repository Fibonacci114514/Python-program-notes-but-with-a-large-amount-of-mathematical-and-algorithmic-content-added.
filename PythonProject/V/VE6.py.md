# `VE6.py` · 列表推导式生成随机数列表

> **摘要**：使用列表推导式（List Comprehension）一行代码生成包含 10 个 0~9 随机整数的列表。这是 Python 中最简洁、最优雅的列表生成方式。

---

#### 💻 代码

```python
from random import *

print([randrange(0, 10) for i in range(10)])
```

---

#### 📖 运行结果

**每次运行结果不同**：
```
[7, 2, 9, 4, 1, 6, 3, 8, 0, 5]
[3, 3, 7, 1, 9, 4, 2, 6, 8, 0]
[5, 8, 2, 4, 9, 1, 7, 3, 6, 0]
```

---

#### 📐 语法拆解

```python
[randrange(0, 10) for i in range(10)]
```

| 部分 | 说明 |
| :--- | :--- |
| `[ ... ]` | 列表推导式的外壳 |
| `randrange(0, 10)` | 生成 0~9 的随机整数（不含 10） |
| `for i in range(10)` | 循环 10 次，每次生成一个随机数 |

**等价于**传统循环：
```python
result = []
for i in range(10):
    result.append(randrange(0, 10))
print(result)
```

列表推导式将 4 行代码压缩为 1 行，且执行效率更高。
