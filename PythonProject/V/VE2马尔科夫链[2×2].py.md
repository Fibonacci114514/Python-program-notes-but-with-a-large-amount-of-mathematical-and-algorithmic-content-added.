# `VE2马尔科夫链[2×2].py` · 二状态马尔可夫链蒙特卡洛模拟

> **摘要**：给定一个 2×2 状态转移矩阵，从指定初始状态出发，模拟 $n$ 步状态演化，重复 10 次蒙特卡洛实验，统计状态 A 和状态 B 出现的频率。这是**随机过程**中马尔可夫链的数值模拟实现。

---

#### 💻 代码

```python
from random import *

P = eval(input('2×2转移矩阵'))

# 检查矩阵是否合法
for i in range(int(len(P))):
    for j in range(int(len(P))):
        if P[i][j] < 0 or P[i][j] > 1:
            print('输入的矩阵数字x应该为概率')
            break
    if sum(P[i]) != 1:
        print('输入的矩阵行上数和不为1')
        break

s = int(input('0or1'))
n = int(input("n="))

# 10次蒙特卡洛模拟
for i in range(10):
    x = ''
    a = b = 0
    for w in range(n):
        if random() <= P[s][0]:
            x += 'a'
            s = 0
            a += 1
        else:
            x += 'b'
            s = 1
            b += 1
    print(a / n, b / n)
```

---

#### 📖 运行示例

**输入**：
```
[[0.7, 0.3], [0.4, 0.6]]
0
1000
```

**输出**（10 次蒙特卡洛实验结果）：
```
0.556 0.444
0.538 0.462
0.561 0.439
...
```

（结果接近平稳分布 $\pi = [0.571, 0.429]$）

---

#### 📐 数学原理

##### 转移矩阵
$$
P = \begin{bmatrix} p_{00} & p_{01} \\ p_{10} & p_{11} \end{bmatrix}
$$

其中 $p_{ij}$ 表示从状态 $i$ 转移到状态 $j$ 的概率。

##### 状态更新规则
- 当前状态为 0：以概率 $p_{00}$ 留在状态 0，以概率 $p_{01}$ 跳到状态 1
- 当前状态为 1：以概率 $p_{10}$ 跳到状态 0，以概率 $p_{11}$ 留在状态 1

##### 平稳分布
对于遍历的马尔可夫链，经过足够多的步数后，状态分布收敛到平稳分布 $\pi$，满足：
$$
\pi P = \pi
$$

对于 2×2 矩阵，平稳分布可解析求解：
$$
\pi_0 = \frac{p_{10}}{p_{01} + p_{10}}, \quad \pi_1 = \frac{p_{01}}{p_{01} + p_{10}}
$$

#### 📐 代码逻辑

| 步骤 | 说明 |
| :--- | :--- |
| 矩阵合法性检查 | 确保所有元素在 $[0,1]$ 内，且每行和为 1 |
| 蒙特卡洛模拟 | 重复 10 次，每次模拟 $n$ 步状态转移 |
| 状态统计 | 记录状态 0（输出 'a'）和状态 1（输出 'b'）的出现次数 |

#### 🧠 与计算理论的关联

马尔可夫链是**概率自动机**（Probabilistic Automaton）的一种特殊形式，在计算理论中用于建模带有随机性的系统。它与**隐马尔可夫模型**（HMM）——语音识别、自然语言处理的核心模型——有直接关联。
