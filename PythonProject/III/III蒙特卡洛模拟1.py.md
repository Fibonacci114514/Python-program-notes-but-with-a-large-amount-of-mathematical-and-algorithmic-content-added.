# `III蒙特卡洛模拟1.py` · 一维随机游走

> **摘要**：模拟一维随机游走（醉汉走路）。从位置 0 开始，每次以 0.5 概率向左或向右移动一步，记录走过的最大位置，并在达到某个条件后停止。

---

#### 💻 代码

```python
def Sprint(n, step, dx):
    if step % dx == 0:
        print('{:^5}'.format(n))
    else:
        print('{:^5}'.format(n), end="|")

from random import *
x = 1
m = x
n = 0
while x > 0:
    w = random()
    if w <= 0.5:
        x = x - 1
        if x > m:
            m = x
    else:
        x = x + 1
    n += 1
    Sprint(x, n, 10)
print()
print(m, n)
```

---

#### 📖 算法分析

- **状态**：当前位置 `x`（初始为 1）
- **转移规则**：$P(\text{左移}) = 0.5$，$P(\text{右移}) = 0.5$
- **终止条件**：`x > 0`（即回到位置 0 时停止）
- **输出**：
  - 每 10 步格式化输出当前位置
  - 最终输出：`m`（最大位移）、`n`（总步数）

---

#### 📐 数学背景

一维随机游走是**随机过程**的基础模型，与**布朗运动**、**扩散过程**等物理学概念相关。该模拟中，从位置 1 出发，最终到达 0 的“首达时”（First Hitting Time）服从离散分布。
