# `IIIE11角谷猜想模拟.py` · 3n+1 猜想

> **摘要**：角谷猜想（3n+1 猜想）是一个著名的未解数学问题。本实验模拟了从任意正整数开始，按照规则（偶数则除以 2，奇数则乘以 3 加 1）迭代，最终收敛到 1 的过程，并利用自定义 `Sprint` 函数格式化输出。

---

#### 💻 代码

```python
def Sprint(n, step, dx):
    if step % dx == 0:
        print('{:^10}'.format(n))
    else:
        print('{:^10}'.format(n), end="|")

n = int(input())
i = 0
while n != 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = n * 3 + 1
    i = i + 1
    Sprint(n, i, 5)
```

---

#### 📖 运行示例

**输入**：`6`

**输出**（每行 5 个值）：
```
    3     |   10     |    5     |   16     |    8     
    4     |    2     |    1     
```

**序列**：6 → 3 → 10 → 5 → 16 → 8 → 4 → 2 → 1

---

#### 📐 数学背景

角谷猜想（Collatz Conjecture）：
- 若 $n$ 为偶数，$n \to n/2$
- 若 $n$ 为奇数，$n \to 3n + 1$

该猜想断言所有正整数最终都会落入 1→4→2→1 的循环。虽已对 $2^{68}$ 以内的数验证成立，但至今未被证明或证伪。
