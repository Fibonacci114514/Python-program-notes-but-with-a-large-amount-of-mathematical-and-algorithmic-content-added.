# `IIIE25线性同余随机数发生器.py` · LCG 伪随机数生成

> **摘要**：实现线性同余发生器（LCG），一种经典的伪随机数生成算法。用户输入初始值 $x_0$、乘数 $a$、增量 $b$、模数 $c$ 和迭代次数 $n$，输出生成的随机序列。

---

#### 💻 代码

```python
x, a, b, c, n = float(input("x=")), float(input("a=")), float(input("b=")), float(input("c=")), int(input("n="))
for i in range(n):
    x = (a * x + b) % c
    print(x)
```

---

#### 📐 数学公式

$$X_{n+1} = (a \cdot X_n + b) \mod c$$

---

#### 📖 运行示例

**输入**：
```
x=3
a=5
b=7
c=8
n=10
```

**输出**：
```
6.0
5.0
0.0
7.0
2.0
1.0
4.0
3.0
6.0
5.0
```

---

#### 🧠 算法要点

- LCG 的周期 ≤ `c`，选择合适的 $a$、$b$、$c$ 可达到满周期。
- 这是 `random` 库的底层实现原理之一（如 C 库的 `rand()`）。
- 参数均为浮点数，适用于需要连续随机数的场景。
