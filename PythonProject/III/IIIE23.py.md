# `IIIE23.py` · 打印等腰三角形

> **摘要**：该程序接收一个字符串和一个整数，用该字符串作为填充字符，打印一个指定高度的等腰三角形。演示了循环嵌套和字符串拼接。

---

#### 💻 代码

```python
str1 = str(input())
a = int(input())
str2 = ""
for b in str1:
    str2 += " "
for i in range(a):
    n = 1
    while n <= a - 1 - i:
        print(str2, end="")
        n += 1
    j = 1
    while j <= 2 * i + 1:
        print(str1, end="")
        j += 1
    print()
```

---

#### 📖 运行示例

**输入**：
```
*
3
```

**输出**：
```
  *
 ***
*****
```

---

#### 📐 逻辑拆解

| 行号 `i` | 前导空格数 | 字符数 |
|----------|-----------|--------|
| 0 | $a-1$ | $1$ |
| 1 | $a-2$ | $3$ |
| 2 | $a-3$ | $5$ |
| ... | ... | ... |
| $i$ | $a-1-i$ | $2i+1$ |
