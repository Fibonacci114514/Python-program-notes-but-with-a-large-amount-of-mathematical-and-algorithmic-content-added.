#### 🧠 关键概念说明

##### 1. 浮点数精度陷阱（test.py）
`round(1.45, 1)` 在某些环境下可能返回 `1.4` 而非期望的 `1.5`。这是因为浮点数在计算机中以二进制存储，`1.45` 无法精确表示，导致舍入偏差。这是**数值分析**中关于“浮点误差”的典型示例。

##### 2. `divmod` 函数（test2.py）
`divmod(x, y)` 是 Python 内置函数，同时返回**整数商**和**余数**，等价于 `(x // y, x % y)`。在离散数学和数论中，这是“欧几里得除法”（Euclidean Division）的直接实现。
