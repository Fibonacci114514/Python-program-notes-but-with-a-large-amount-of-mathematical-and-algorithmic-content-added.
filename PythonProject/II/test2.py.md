# `test2.py` · 整除与取模

> **摘要**：演示了如何使用 `divmod()` 函数同时获取商和余数，以及如何使用 `format()` 方法进行格式化输出。这是一个典型的“输入-处理-输出”模型。

---

#### 💻 代码

```python
x = int(input())
y = int(input())
n, mod = divmod(x, y)
print('{}/{}={}......{}'.format(x, y, n, mod))
```

---

#### 📖 语法拆解

##### 1. `divmod(x, y)`
- 内置函数，返回一个包含**商**和**余数**的元组 `(x // y, x % y)`。
- 适用于整数和浮点数。

##### 2. `str.format()` 字符串格式化
- `'{}...{}'.format(a, b)` 用于将变量填充到占位符 `{}` 中。
- 效果等同于 `f"{x}/{y}={n}......{mod}"`（f-string 是更现代的写法）。
