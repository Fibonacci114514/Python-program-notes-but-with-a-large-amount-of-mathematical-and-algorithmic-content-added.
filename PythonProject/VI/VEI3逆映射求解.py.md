# `VEI3逆映射求解.py` · 字典逆映射（值唯一检查）

> **摘要**：接收一个字典，检查其所有值是否互不相同（即映射是否为单射），如果是，则交换键和值，生成逆映射字典。这是对数学中**反函数**概念的编程实践。

---

#### 💻 代码

```python
a = eval(input())
b = {}
if len(set(a.keys())) == len(set(a.values())):
    for i in a.keys():
        b[a[i]] = i
    print(b)
else:
    print("error")
```

---

#### 📖 运行示例

**输入**：
```
{'a': 1, 'b': 2, 'c': 3}
```

**输出**：
```
{1: 'a', 2: 'b', 3: 'c'}
```

**输入**（值有重复）：
```
{'a': 1, 'b': 1, 'c': 3}
```

**输出**：
```
error
```

---

#### 📐 数学背景

- **单射（Injective）**：每个值最多对应一个键，即值互不相同。
- **满射（Surjective）**：每个值都有对应的键（当定义域和值域大小相等时由单射保证）。
- **双射（Bijective）**：同时是单射和满射，存在逆映射。

**条件**：`len(set(a.keys())) == len(set(a.values()))` 等价于“键数量 == 不同值的数量”，即所有值互不相同。

**潜在问题**：即使值互不相同，但值的集合与键的集合大小相等时，逆映射的定义域与原映射的值域一致，反函数存在。
