# `VIE6凯撒密码映射.py` · 凯撒密码映射表构造

> **摘要**：根据用户输入的偏移量，构造一个小写字母的凯撒密码映射表（字典）。映射表将每个字母映射到其移位后的对应字母。

---

#### 💻 代码

```python
d = {}
dx = int(input())
for i in range(26):
    d[chr(i + ord('a'))] = chr((i + dx) % 26 + ord('a'))
print(d)
```

---

#### 📖 运行示例

**输入**：`3`

**输出**：
```
{'a': 'd', 'b': 'e', 'c': 'f', 'd': 'g', 'e': 'h', 'f': 'i', 'g': 'j', 'h': 'k', 'i': 'l', 'j': 'm', 'k': 'n', 'l': 'o', 'm': 'p', 'n': 'q', 'o': 'r', 'p': 's', 'q': 't', 'r': 'u', 's': 'v', 't': 'w', 'u': 'x', 'v': 'y', 'w': 'z', 'x': 'a', 'y': 'b', 'z': 'c'}
```

---

#### 📐 数学公式

对于每个字母 $c$（位置索引 $i$）：
$$
E(i) = (i + shift) \bmod 26
$$

其中 $i = \text{ord}(c) - \text{ord}('a')$。

**公式对应**：
- `chr(i + ord('a'))`：原始字母（键）
- `chr((i + dx) % 26 + ord('a'))`：移位后的字母（值）
