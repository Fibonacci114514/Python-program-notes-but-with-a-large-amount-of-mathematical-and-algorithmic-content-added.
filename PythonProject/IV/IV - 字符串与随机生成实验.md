# 🔤 IV - 字符串与随机生成实验

> **摘要**：本模块专注于文本数据的处理、随机数据的构造，以及简单的形式语言/字符串重写系统。包含了基础的字符串反转、字符类型统计、凯撒密码（Caesar Cipher）实现，以及平方取中随机数发生器、随机列表/字符串构造器等工具。特别地，`字符串替代系统.py.md` 引入了**形式语言**（Formal Language）中字符串重写（Rewriting System）的基本概念。

#### 🧠 数学与算法亮点

##### 1. 凯撒密码（IVE3）
涉及**模运算**（Modulo Operation）在密码学中的应用：
$$E(x) = (x + shift) \bmod 26$$
这是理解**对称加密**（Symmetric Encryption）的入门钥匙。

##### 2. 平方取中发生器（IVE1）
由冯·诺依曼在 1946 年提出的早期伪随机数生成方法：
- 取一个 4 位数种子 $S$
- 计算 $S^2$，取中间 4 位作为下一个随机数
- 该方法的缺陷：容易陷入周期短或退化为 0（被称为“随机数塌缩”）
- 是**计算随机性**（Computational Randomness）的历史性案例

##### 3. 字符串替代系统（字符串替代系统.py.md）
该程序实现了一个简单的**字符串重写系统**（Rewriting System）：
- 规则：`a → cb`，`b → bac`，`c → bb`
- 每次迭代并行替换所有字符
- 这是 **L-system**（Lindenmayer system）的雏形，用于模拟植物生长、分形生成等
- 在**计算理论**中，字符串重写系统与**半 Thue 系统**、**形式文法**（Chomsky Hierarchy）紧密相关

**迭代示例**（从 `"a"` 开始）：
```
第0轮: a
第1轮: cb
第2轮: bbbc
第3轮: bacbacbbbb
...
```
