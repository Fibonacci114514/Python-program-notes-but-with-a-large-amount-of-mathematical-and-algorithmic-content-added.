# `IVE1平方取中发生器.py` · 平方取中随机数发生器

> **摘要**：实现冯·诺依曼提出的平方取中法（Middle-square method）伪随机数生成器。使用全局变量 `seed` 维护状态，每次取平方后提取中间 4 位作为随机数。

---

#### 💻 代码

```python
seed = 2333

def random4():
    global seed
    seed = seed ** 2
    return int(str(seed)[1:5])

for i in range(10):
    print(random4())
```

---

#### 📖 运行结果

```
4438
6948
...
```

---

#### 📐 算法原理

**步骤**：
1. 种子 $S$ 是一个 4 位数（如 2333）
2. 计算 $S^2$（如 $2333^2 = 5442889$）
3. 将结果转为字符串，取中间 4 位作为新的随机数
4. 重复上述步骤

**缺陷**：
- 容易出现周期短（很快就进入循环）
- 可能退化为 0（一旦出现 0，后续全为 0）
- 冯·诺依曼本人称之为“数字的疯狂”（madness of numbers）

---

#### 🧠 历史背景

平方取中法是 **1946 年冯·诺依曼** 在 ENIAC 计算机上实现的随机数生成器。虽然它本身有缺陷，但它开启了**伪随机数生成器**（PRNG）的研究领域。现代 PRNG（如 LCG、梅森旋转）在统计质量上远超平方取中法。
