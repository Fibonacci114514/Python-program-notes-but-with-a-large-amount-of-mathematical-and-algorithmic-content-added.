# `IVE3凯撒密码.py` · 凯撒密码

> **摘要**：实现凯撒密码加密。用户输入一个字符串和一个偏移量，程序对字符串中的大写字母、小写字母和数字分别进行移位加密，其他字符保持不变。

---

#### 💻 代码

```python
s1 = input()
s2 = list(s1)
s3 = ''
x = int(input())
for i in s2:
    if i.islower():
        s3 += chr(ord('a') + (ord(i) + x + 7) % (ord('z') - ord('a') + 1))
    elif i.isupper():
        s3 += chr(ord('A') + (ord(i) + x + 13) % (ord('Z') - ord('A') + 1))
    elif i.isdigit():
        s3 += chr(ord('0') + (ord(i) + x + 2) % (ord('9') - ord('0') + 1))
    else:
        s3 += i
print(s3)
```

---

#### 📖 运行示例

**输入**：
```
Hello
3
```

**输出**：
```
Khoor
```

---

#### 📐 数学公式

对于小写字母：
$$E(c) = ((c - 'a') + shift) \bmod 26 + 'a'$$

但代码中使用了 `(ord(i) + x + 7) % 26`，其中的 `+7` 是为了抵消某种偏移。标准的凯撒密码公式应为：

```python
# 标准写法
s3 += chr(ord('a') + (ord(i) - ord('a') + x) % 26)
```

---

#### ⚠️ 代码注意

1. 数字部分使用了 `+2` 偏移修正，可能与预期行为相关。
2. 该实现对大小写字母和数字分别处理，保持非字母数字字符不变，是凯撒密码的实用版本。
