# `IVE字符串反转.py` · 字符串反转

> **摘要**：演示了两种反转字符串的方法：手动循环拼接与 Python 切片 `[::-1]`。切片方式是 Python 中最优雅、最高效的反转方法。

---

#### 💻 代码

```python
x = input()
l = len(x)
y = ''
for i in range(0, len(x)):
    y = y + x[l - i - 1]
print(y, x[::-1])
```

---

#### 📖 运行示例

**输入**：`hello`

**输出**：
```
olleh olleh
```

---

#### 📐 方法对比

| 方法 | 代码 | 时间复杂度 | 优点 |
| :--- | :--- | :--- | :--- |
| 手动循环拼接 | `y = y + x[l-i-1]` | $O(n)$ | 逻辑直观 |
| 切片反转 | `x[::-1]` | $O(n)$ | 简洁高效，Pythonic |
