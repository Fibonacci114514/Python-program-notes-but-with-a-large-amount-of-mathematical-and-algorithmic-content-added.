# `IVE随机列表构造器.py` · 随机整数列表生成器

> **摘要**：生成一个指定长度的随机整数列表，元素范围在 0 到 100000 之间。演示了 `random.randrange` 和列表拼接 `+=` 的用法。

---

#### 💻 代码

```python
from random import *
x = []
n = int(input())
for i in range(n):
    x += [int(randrange(0, 100000 + 1))]
print(x)
```

---

#### 📖 运行示例

**输入**：`5`

**输出**（每次运行结果不同）：
```
[37264, 91382, 5381, 72048, 19463]
```

---

#### 📐 代码解析

| 语法 | 说明 |
| :--- | :--- |
| `from random import *` | 导入 `random` 库的所有函数 |
| `randrange(0, 100000 + 1)` | 生成 `[0, 100000]` 范围内的随机整数 |
| `x += [value]` | 列表拼接，等价于 `x.append(value)` |
