> **摘要**:元组(tuple)与列表类似,但元组是不可变的——一旦创建,其元素不能被修改,添加或删除.本文将元组定位为“只读列表”,系统介绍其定义方式,与列表的对比,适用场景,并强调单元素元组的特殊语法.

---

#### 1. 元组的定义

元组用圆括号 `()` 表示(但更准确地说,是**逗号**定义了元组).

```python
# 标准定义
tupScores = (98, 96, 95, 94, 92)

# 不加括号(逗号定义)
tupScores = 98, 96, 95, 94, 92
print(type(tupScores))   # <class 'tuple'>
```

##### 1.1 单元素元组(易错点！)

```python
# ❌ 错误:视为字符串
tupNames = ("萧峰")
print(type(tupNames))    # <class 'str'>

# ✅ 正确:加逗号
tupNames = ("萧峰",)
print(type(tupNames))    # <class 'tuple'>

# 不加括号的逗号也能定义
tupNames = "萧峰",
print(type(tupNames))    # <class 'tuple'>
```

> **规则**:单元素元组必须在元素后加一个逗号 `,`,否则 Python 会将其视为普通类型.

##### 1.2 空元组

```python
empty = ()
print(type(empty))   # <class 'tuple'>
```

#### 2. 元组的不可变性

元组创建后,**不能**:
- 修改元素
- 添加元素
- 删除元素(但可删除整个元组)

```python
tup = (98, 96, 95)

# 尝试修改 → 报错
tup[0] = 100
# TypeError: 'tuple' object does not support item assignment

# 尝试追加 → 报错
tup.append(94)
# AttributeError: 'tuple' object has no attribute 'append'

# 可以删除整个元组
del tup   # 之后 tup 不再可用
```

#### 3. 元组支持的操作(只读)

元组支持所有不修改列表的操作:

| 操作 | 列表 | 元组 | 说明 |
|------|------|------|------|
| 读元素 `t[i]` | ✅ | ✅ | 索引访问 |
| 切片 | ✅ | ✅ | `t[start:end:step]` |
| `len()` | ✅ | ✅ | 求长度 |
| `in` / `not in` | ✅ | ✅ | 成员判断 |
| `index()` | ✅ | ✅ | 查找索引 |
| `count()` | ✅ | ✅ | 计数 |
| 遍历 | ✅ | ✅ | `for item in t:` |
| `max()` / `min()` | ✅ | ✅ | 数值元组可用 |
| `sum()` | ✅ | ✅ | 数值元组可用 |
| `sorted()` | ✅ | ✅ | 返回列表,原元组不变 |
| `+` 拼接 | ✅ | ✅ | 返回新元组 |
| `*` 重复 | ✅ | ✅ | 返回新元组 |
| `sort()` | ✅ | ❌ | 无原地排序 |
| `append()` | ✅ | ❌ | 不可添加 |
| `insert()` | ✅ | ❌ | 不可插入 |
| `pop()` | ✅ | ❌ | 不可弹出 |
| `remove()` | ✅ | ❌ | 不可删除 |
| `extend()` | ✅ | ❌ | 不可扩充 |
| `copy()` | ✅ | ❌ | 无该方法 |
| 赋值修改 | ✅ | ❌ | 不可变 |

#### 4. 元组的适用场景

| 场景 | 原因 |
|------|------|
| **函数返回多个值** | 自动打包为元组 |
| **字典键** | 元组不可变,可作键；列表不可 |
| **坐标点,RGB值** | 固定结构,不应被修改 |
| **常量数据集** | 防止意外修改 |
| **参数传递** | 保证函数内部不会修改数据 |

**示例:函数返回多个值**

```python
def divmod_example(a, b):
    return a // b, a % b

quotient, remainder = divmod_example(10, 3)
print(quotient, remainder)   # 3 1
```

---

#### 5. 元组与列表的转换

```python
# 列表 → 元组
lst = [1, 2, 3]
tup = tuple(lst)
print(tup)   # (1, 2, 3)

# 元组 → 列表
tup = (4, 5, 6)
lst = list(tup)
print(lst)   # [4, 5, 6]
```

---

#### 6. 命名元组(`namedtuple`)拓展

若需“带字段名的元组”,可使用 `collections.namedtuple`:

```python
from collections import namedtuple
Point = namedtuple('Point', ['x', 'y'])
p = Point(3, 4)
print(p.x, p.y)   # 3 4
print(p[0], p[1]) # 3 4(仍支持索引)
```

适用于轻量级数据类,兼具元组的不可变性和类属性访问的便利性.

#### 8. 快速参考

```python
# 定义
t = (1, 2, 3)
t = 1, 2, 3          # 逗号定义
t = (1,)             # 单元素(加逗号)
t = ()               # 空元组

# 访问
t[0]                 # 1
t[0:2]               # (1, 2)
len(t)               # 3
1 in t               # True

# 遍历
for x in t:
    print(x)

# 解包
a, b, c = t
```

> **总结**:元组是 Python 中的“不可变列表”,适用于需要数据保护或作为字典键的场景.其简洁性和安全性使其在函数返回值,数据记录和常量集合中广泛应用.理解元组的不可变性,有助于写出更安全,意图更清晰的代码.
