> **摘要**:序列类型(字符串,列表,元组)之间可以相互转换.本文介绍 `list()`,`tuple()`,`split()`,`zip()` 和 `enumerate()` 等核心转换函数,帮助你在不同序列类型间灵活切换,适应不同场景的需求.

---

#### 1. 什么是序列

序列(sequence)是 Python 中的一种基本数据类型,其最大特点是**元素有序**,通过索引访问.常见的序列类型包括:

- **字符串** (`str`):字符序列,不可变
- **列表** (`list`):任意类型序列,可变
- **元组** (`tuple`):任意类型序列,不可变

---

#### 2. `list()` 与 `tuple()` 互相转换

```python
# 列表 → 元组
lst = [1, 2, 3, 4]
tup = tuple(lst)
print(tup)   # (1, 2, 3, 4)
print(type(tup))   # <class 'tuple'>

# 元组 → 列表
tup = (5, 6, 7)
lst = list(tup)
print(lst)   # [5, 6, 7]
print(type(lst))   # <class 'list'>
```

##### 2.1 字符串 → 列表

```python
# 方式一:list() 逐个字符拆分
s = "hello"
chars = list(s)          # ['h', 'e', 'l', 'l', 'o']

# 方式二:split() 按分隔符拆分(常用)
s = "a,b,c,d"
parts = s.split(",")     # ['a', 'b', 'c', 'd']

# 默认按空白拆分
words = "Hello world Python".split()   # ['Hello', 'world', 'Python']
```

##### 2.2 列表 → 字符串

使用 `join()` 方法(字符串的方法):

```python
words = ["Python", "is", "fun"]
s = " ".join(words)      # 'Python is fun'
s2 = "-".join(words)     # 'Python-is-fun'
```

#### 3. `zip()` — 并行迭代多个序列

`zip()` 将多个序列中对应位置的元素打包为元组,返回一个迭代器.

```python
names = ["张三", "李四", "王五"]
scores = [85, 92, 78]

pairs = list(zip(names, scores))
print(pairs)   # [('张三', 85), ('李四', 92), ('王五', 78)]

# 遍历使用
for name, score in zip(names, scores):
    print(f"{name}: {score}")
```

**与列表生成式结合**:创建字典

```python
d = dict(zip(names, scores))
print(d)   # {'张三': 85, '李四': 92, '王五': 78}
```

#### 4. `enumerate()` — 同时获取索引和值

`enumerate()` 在遍历序列时同时提供索引和值,常用于需要知道元素位置的场景.

```python
names = ["萧峰", "杨过", "令狐冲"]

# 基本用法
for i, name in enumerate(names):
    print(f"{i}: {name}")
# 输出:
# 0: 萧峰
# 1: 杨过
# 2: 令狐冲

# 可指定起始索引
for i, name in enumerate(names, start=1):
    print(f"{i}: {name}")
# 1: 萧峰
# 2: 杨过
# 3: 令狐冲
```

#### 5. 综合示例

##### 5.1 字符串 → 列表 → 元组

```python
s = "3.14,2.72,1.62"
lst = s.split(",")                # ['3.14', '2.72', '1.62']
nums = [float(x) for x in lst]    # [3.14, 2.72, 1.62]
tup = tuple(nums)                 # (3.14, 2.72, 1.62)
print(tup)
```

##### 5.2 使用 `zip` 构建成绩表

```python
names = ["Alice", "Bob", "Charlie"]
math = [90, 85, 88]
physics = [92, 80, 85]

for name, m, p in zip(names, math, physics):
    print(f"{name}: 数学{m}, 物理{p}")
```

##### 5.3 使用 `enumerate` 查找最大值索引

```python
scores = [85, 92, 78, 90, 88]
max_idx = 0
for i, score in enumerate(scores):
    if score > scores[max_idx]:
        max_idx = i
print(f"最高分是 {scores[max_idx]},在索引 {max_idx} 处")
```

#### 6. 转换函数速查表

| 函数 | 输入 | 输出 | 描述 |
|------|------|------|------|
| `list(iterable)` | 可迭代对象 | `list` | 转换为列表 |
| `tuple(iterable)` | 可迭代对象 | `tuple` | 转换为元组 |
| `str.split(sep)` | 字符串 | `list` | 按分隔符拆分为列表 |
| `sep.join(list)` | 字符串列表 | `str` | 用分隔符连接为字符串 |
| `zip(seq1, seq2, ...)` | 多个序列 | 元组迭代器 | 并行打包 |
| `enumerate(seq)` | 序列 | (索引, 值) 迭代器 | 带索引遍历 |

---

> **总结**:序列转换函数让不同数据结构之间的数据流动变得平滑.`list()` 和 `tuple()` 是基础转换,`split()` / `join()` 是字符串与列表之间的桥梁,`zip()` 和 `enumerate()` 让多序列操作和遍历更加高效.掌握这些工具,你就能在不同的数据形态间自由切换,应对各种数据处理需求.
