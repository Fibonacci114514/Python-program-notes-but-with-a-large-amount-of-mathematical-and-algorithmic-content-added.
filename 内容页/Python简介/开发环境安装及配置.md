#### 1. 安装 Python 解释器(基础必选)

##### 1.1 官方 Python 下载
- **官网地址**:[https://www.python.org/downloads/](https://www.python.org/downloads/)
- 选择适合您操作系统的 **Python 3.x** 最新稳定版本(当前推荐 ≥ 3.10).
  - Windows:下载 `.exe` 安装包.
  - macOS:下载 `.pkg` 或使用 Homebrew(`brew install python`).
  - Linux:使用系统包管理器(如 `sudo apt install python3`)或源码编译.

##### 1.2 安装注意事项(Windows 特别提示)
- ✅ **勾选“Add Python to PATH”**(将 Python 加入环境变量),否则无法在命令行中使用 `python` 命令.
- 建议选择 **“Customize installation”**,确保安装 `pip`(包管理工具)和 `IDLE`(简单集成环境).
- 安装路径可保留默认(`C:\Users\用户名\AppData\Local\Programs\Python\Python3xx`)或改为根目录(如 `C:\Python3xx`)以方便查找.

##### 1.3 验证安装
打开终端(Terminal / CMD / PowerShell),输入:
```bash
python --version
```
若正确显示版本号(如 `Python 3.12.3`),则安装成功.

#### 2. 科学计算发行版推荐:Anaconda(强烈推荐)

如果您的学习重点在**数学,数据科学,机器学习**,建议直接安装 **Anaconda**(或轻量版 **Miniconda**).

- **Anaconda** 内置了 200+ 常用库(NumPy, SciPy, Pandas, Matplotlib, Jupyter Notebook 等),免去逐个安装的麻烦.
- **下载地址**:[https://www.anaconda.com/download](https://www.anaconda.com/download)(同样只从官网获取!)
- 安装完成后,通过 **Anaconda Navigator** 图形界面或 `conda` 命令管理环境和包.

##### 2.1 Miniconda(轻量选择)
若硬盘空间有限或只想按需安装库,可选用 **Miniconda** —— 仅包含 Python 和 conda 包管理器,后续自行安装所需库.
- 下载地址:[https://docs.conda.io/en/latest/miniconda.html](https://docs.conda.io/en/latest/miniconda.html)

#### 3. 代码编辑器与集成开发环境(IDE)

| 工具 | 适用场景 | 特点 |
|------|----------|------|
| **VS Code** | 通用开发(强烈推荐) | 轻量,插件丰富(Python,Jupyter,Git),调试方便 |

> **数学/算法学习建议**:使用 **Jupyter Notebook**(或 JupyterLab)进行数学推导和算法演示,体验极佳.

#### 4. 虚拟环境管理(隔离项目依赖)

为避免不同项目间包版本冲突,推荐使用虚拟环境.常用工具:
- **`venv`**(Python 内置):`python -m venv myenv`
- **`conda`**(Anaconda 环境):`conda create -n myenv python=3.12`
- 激活环境后,用 `pip install` 安装特定版本的包,互不影响.

#### 5. 验证科学计算库安装(数学基础库)

安装完成后,建议运行以下测试代码,确保核心库正常工作:
```python
import numpy as np
import scipy
import matplotlib.pyplot as plt
import sympy as sp

# 数值计算示例
x = np.linspace(0, 2*np.pi, 100)
y = np.sin(x)
plt.plot(x, y)
plt.title("sin(x) 函数图像")
plt.show()

# 符号计算示例
t = sp.symbols('t')
f = sp.sin(t) * sp.exp(-t)
print(sp.integrate(f, (t, 0, sp.oo)))  # 输出积分结果
```

若无报错,则环境已成功配置.

> **Python 是完全免费开源的**,官方安装包不会要求付费,绑定银行卡或收集个人隐私.**务必从本笔记提供的正规链接下载**,切勿使用搜索引擎中的“破解版”,“高速下载”,“一键安装”等不明来源的安装包.

- 安装包捆绑恶意软件,广告插件或修改浏览器主页.
- 安装后提示“激活”或“购买许可证”.

**正规来源唯一可靠**:
- Python 官方:`python.org`
- Anaconda 官方:`anaconda.com`
