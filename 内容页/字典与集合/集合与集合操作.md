> **摘要**:Python 中的集合(set)与数学集合概念高度一致——用于存放一组无序且互不相同的元素.集合支持添加,删除,成员判断等基本操作,更支持并集,交集,差集,对称差集等数学运算.本文系统介绍集合的定义,操作及集合运算,强调去重与关系测试两大应用场景,帮助读者将离散数学中的集合论知识转化为可执行的 Python 代码.

---

#### 1. 集合的定义与特性

集合(set)是 Python 中的一种无序,不重复的元素容器,与数学集合完全对应.

**核心特性**:
- **无序**:元素没有顺序,不能通过索引访问.
- **互异性**:自动去重,每个元素只出现一次.
- **元素要求**:元素必须是**不可变类型**(如数字,字符串,元组),因为集合内部基于哈希表实现.
- **可变性**:集合本身是可变的,可添加或删除元素.

**与数学对应**:
- 数学中的集合 $\{1, 2, 3\}$ 对应 Python 的 `{1, 2, 3}`.
- 集合元素不可变对应数学中集合的元素是确定的,不可修改的.

#### 2. 集合的创建

##### 2.1 直接使用大括号 `{}`

```python
# 整数集合
s1 = {1, 2, 3, 4, 5}

# 字符串集合(自动去重)
s2 = {"apple", "banana", "apple", "orange"}
print(s2)   # {'orange', 'banana', 'apple'}(顺序不保证)

# 混合类型(但元素必须不可变)
s3 = {1, "hello", (2, 3)}
```

##### 2.2 使用 `set()` 函数(从序列转换)

```python
# 从列表转换(自动去重)
lst = [1, 2, 2, 3, 3, 4]
s = set(lst)
print(s)   # {1, 2, 3, 4}

# 从字符串转换(字符集合)
s = set("hello")
print(s)   # {'h', 'e', 'l', 'o'}(去重且无序)

# 从元组转换
s = set((1, 2, 3, 3))
print(s)   # {1, 2, 3}
```

##### 2.3 空集合

```python
# ❌ 错误:{} 创建的是空字典
empty_dict = {}
print(type(empty_dict))   # <class 'dict'>

# ✅ 正确:使用 set()
empty_set = set()
print(type(empty_set))    # <class 'set'>
```

##### 2.4 集合推导式

与列表生成式类似,集合也支持推导式:

```python
# 1~10 中偶数的平方集合
s = {x**2 for x in range(1, 11) if x % 2 == 0}
print(s)   # {64, 4, 36, 100, 16}
```

#### 3. 集合的基本操作

| 操作 | 方法/语法 | 说明 |
|------|-----------|------|
| 添加单元素 | `s.add(item)` | 添加一个元素,若已存在则无变化 |
| 添加多元素 | `s.update(iterable)` | 从可迭代对象中添加元素(拆分后加入) |
| 删除元素(报错版) | `s.remove(item)` | 删除指定元素,不存在则报 `KeyError` |
| 删除元素(安全版) | `s.discard(item)` | 删除指定元素,不存在则静默忽略 |
| 随机删除并返回 | `s.pop()` | 删除并返回一个任意元素,空集合报错 |
| 清空集合 | `s.clear()` | 移除所有元素 |
| 成员判断 | `item in s` | 返回 `True` / `False` |

```python
s = {1, 2, 3}

# 添加
s.add(4)                # {1, 2, 3, 4}
s.update([5, 6, 6])     # {1, 2, 3, 4, 5, 6}(重复自动去重)

# 删除
s.remove(3)             # {1, 2, 4, 5, 6}
s.discard(10)           # 无变化,不报错
item = s.pop()          # 随机弹出一个元素

# 成员判断
print(2 in s)           # True
print(10 in s)          # False
```

#### 4. 集合的数学运算(核心)

Python 集合完整支持数学中的集合运算,可通过运算符或方法实现.

##### 4.1 并集(Union):$A \cup B$

```python
A = {1, 2, 3, 4, 5}
B = {4, 5, 6, 7, 8}

# 运算符
print(A | B)   # {1, 2, 3, 4, 5, 6, 7, 8}

# 方法
print(A.union(B))   # {1, 2, 3, 4, 5, 6, 7, 8}
```

##### 4.2 交集(Intersection):$A \cap B$

```python
print(A & B)          # {4, 5}
print(A.intersection(B))   # {4, 5}
```

##### 4.3 差集(Difference):$A \setminus B$

```python
print(A - B)          # {1, 2, 3}
print(A.difference(B))   # {1, 2, 3}
```

##### 4.4 对称差集(Symmetric Difference):$A \triangle B$

对称差集 = 并集 − 交集,即只属于其中一个集合的元素.

```python
print(A ^ B)   # {1, 2, 3, 6, 7, 8}
print(A.symmetric_difference(B))   # {1, 2, 3, 6, 7, 8}
```

**韦恩图对应**:

| 运算 | 运算符 | 方法 |
|------|--------|------|
| $A \cup B$ | `\|` | `union()` |
| $A \cap B$ | `&` | `intersection()` |
| $A \setminus B$ | `-` | `difference()` |
| $A \triangle B$ | `^` | `symmetric_difference()` |

#### 5. 集合的关系判断

| 操作 | 方法 | 说明 |
|------|------|------|
| 子集 | `A.issubset(B)` | $A \subseteq B$ |
| 真子集 | 不支持直接运算符 | 可用 `A < B`(需 Python 3.9+) |
| 超集 | `A.issuperset(B)` | $A \supseteq B$ |
| 不相交 | `A.isdisjoint(B)` | $A \cap B = \varnothing$ |

```python
A = {1, 2, 3}
B = {1, 2, 3, 4, 5}

print(A.issubset(B))      # True
print(B.issuperset(A))    # True
print(A.isdisjoint({6, 7}))  # True
```

#### 6. 综合应用示例

##### 6.1 列表去重(经典用法)

```python
lst = [1, 2, 2, 3, 4, 4, 5, 5, 5]
unique = list(set(lst))
print(unique)   # [1, 2, 3, 4, 5](顺序可能不同)
```

若需保持原顺序,可用 `dict.fromkeys()`:

```python
unique_ordered = list(dict.fromkeys(lst))
print(unique_ordered)   # [1, 2, 3, 4, 5](顺序保持)
```

##### 6.2 编程语言排行榜分析

**问题**:IEEE 榜 {Python, C++, C, Java, C#} 与 TIOBE 榜 {Java, C, Python, C++, VB.NET},求:
1. 所有上榜语言(并集)
2. 两个榜单同时进前五的语言(交集)
3. 只在 IEEE 榜的语言(差集)
4. 只出现在一个榜单的语言(对称差集)

```python
ieee = {"Python", "C++", "C", "Java", "C#"}
tiobe = {"Java", "C", "Python", "C++", "VB.NET"}

all_langs = ieee | tiobe                    # 并集
both = ieee & tiobe                         # 交集
only_ieee = ieee - tiobe                    # 差集
only_one = ieee ^ tiobe                     # 对称差集

print("全部上榜语言:", all_langs)
print("同时上榜:", both)
print("仅 IEEE:", only_ieee)
print("仅一个榜单:", only_one)
```

#### 7. 与数学/算法的关联

| 数学概念 | Python 实现 | 算法应用 |
|----------|-------------|----------|
| 集合 $S$ | `set` | 去重,成员判断 $O(1)$ |
| 并集 $A \cup B$ | `A \| B` | 合并两个集合 |
| 交集 $A \cap B$ | `A & B` | 共同元素查询 |
| 差集 $A \setminus B$ | `A - B` | 排除特定元素 |
| 对称差 $A \triangle B$ | `A ^ B` | 异或关系(仅属其一) |
| 子集 $A \subseteq B$ | `A.issubset(B)` | 包含关系判定 |
| 空集 $\varnothing$ | `set()` | 初始集合 |

**常见算法场景**:
- 图论中的顶点集,边集
- 数据清洗中的重复值处理
- 集合覆盖问题(贪心算法)
- 关联规则挖掘(频繁项集)

#### 8. 注意事项与常见陷阱

| 陷阱 | 说明 |
|------|------|
| `{}` 是空字典,不是空集合 | 空集合必须用 `set()` |
| 集合元素必须不可变 | 列表不能作为集合元素,可用元组替代 |
| 集合无序 | 不能依赖顺序,遍历结果不确定 |
| 集合去重时注意浮点数精度 | `1.0` 和 `1` 被视为相同 |
| `pop()` 随机性 | 不要依赖 `pop()` 的返回值顺序 |
