> **摘要**:文件是程序与外部存储交互的桥梁,实现了数据的持久化保存.本文系统讲解文件的概念,目录结构,路径表示(绝对/相对路径),以及文件打开,读写,关闭的完整流程.重点分析文件指针在读写操作中的移动机制,帮助读者理解不同打开模式(`r`,`w`,`a`)对指针位置的影响,为数据持久化处理奠定基础.

---

#### 1. 文件的基本概念

**文件** 是一组相关数据的集合,以特定格式存储在外部存储器(如硬盘)上.

##### 1.1 文件的分类

| 类型 | 说明 | 示例 |
|------|------|------|
| **文本文件** | 存储字符数据,人类可读 | `.txt`,`.py`,`.csv` |
| **二进制文件** | 存储原始字节数据,非人类可读 | 图片(`.jpg`),音频(`.mp3`),视频 |

##### 1.2 文件名结构

```
主文件名 . 扩展名
    ↑         ↑
 用户命名   文件类型标识
```

- 主文件名:由用户自行命名,体现内容.
- 扩展名:标识文件类型,系统据此选择默认打开程序.

---

#### 2. 目录与文件路径

##### 2.1 目录(文件夹)

- **文件** 组织和管理相关数据.
- **目录(文件夹)** 组织和管理相关文件,可包含子目录.

##### 2.2 路径的两种表示方式

文件在存储系统中的位置称为**路径**.

| 路径类型 | 起点 | 示例(Windows) |
|----------|------|----------------|
| **绝对路径** | 从盘符(根目录)开始 | `F:\documents\python\data.txt` |
| **相对路径** | 从当前工作目录开始 | `data.txt` 或 `./data/data.txt` |

```python
import os

# 查看当前工作目录(CWD)
print(os.getcwd())

# 修改当前工作目录
os.chdir("F:/documents")
print(os.getcwd())   # F:/documents
```

**路径表示注意事项**:
- Windows 路径分隔符通常用反斜杠 `\`,但在 Python 字符串中需转义为 `\\`,或使用原始字符串 `r"F:\documents"`,更推荐使用正斜杠 `/`(跨平台兼容).

#### 3. 文件操作的三步流程

```
① 打开文件(内存 ← 外存)
        ↓
② 读文件 / 写文件
        ↓
③ 关闭文件(内存 → 外存)
```

##### 3.1 打开文件:`open()`

```python
文件对象 = open(文件路径, 打开模式)
```

| 参数 | 说明 |
|------|------|
| 文件路径 | 绝对路径或相对路径 |
| 打开模式 | 指定文件类型(文本/二进制)和操作方式(读/写/追加) |

##### 3.2 关闭文件:`close()`

```python
文件对象.close()
```

- 将内存中的数据**保存回外存**.
- 释放文件占用的系统资源.
- **重要**:忘记关闭文件可能导致数据丢失或资源泄漏.

##### 3.3 推荐方式:`with` 语句(自动关闭)

```python
with open("data.txt", "r") as f:
    content = f.read()
# 离开 with 代码块时,文件自动关闭
```

#### 4. 文件指针(核心概念)

**文件指针** 是一个隐式的游标,标识当前读写操作在文件中的位置.每次读写操作都会使指针向前移动相应字节数.

```
文件内容:Hello World
            ↑
         文件指针(初始在开头)

读取 5 个字符后:
Hello World
     ↑
  指针在 ' ' 位置
```

**不同打开模式对指针初始位置的影响**:

| 模式 | 指针初始位置 |
|------|-------------|
| `'r'` | 文件开头 |
| `'w'` | 文件开头(文件被清空) |
| `'a'` | 文件末尾(EOF) |
| `'r+'` | 文件开头 |
| `'w+'` | 文件开头(文件被清空) |
| `'a+'` | 文件末尾 |

**操作对指针位置的影响**:
- `read(n)`:向后移动 n 个字符(或字节).
- `readline()`:移动到下一行开头.
- `write(str)`:从指针当前位置写入,指针后移.
- `seek(offset)`:**手动移动指针**到指定位置(见 §6.3).

---

#### 5. 打开模式详解

| 模式 | 文件类型 | 操作方式 | 文件不存在时 | 指针初始位置 | 是否清空原内容 |
|------|----------|----------|--------------|--------------|----------------|
| `'r'` | 文本 | 只读 | 报错 | 开头 | — |
| `'r+'` | 文本 | 读写 | 报错 | 开头 | 否(覆盖写入) |
| `'w'` | 文本 | 只写 | **创建** | 开头 | **是(清空)** |
| `'w+'` | 文本 | 读写 | **创建** | 开头 | **是(清空)** |
| `'a'` | 文本 | 只写(追加) | **创建** | **末尾** | 否 |
| `'a+'` | 文本 | 读写(追加) | **创建** | **末尾** | 否 |
| `'rb'` | 二进制 | 只读 | 报错 | 开头 | — |
| `'wb'` | 二进制 | 只写 | **创建** | 开头 | **是(清空)** |
| `'ab'` | 二进制 | 只写(追加) | **创建** | **末尾** | 否 |

> **与文件指针的关联**:
> - `'w'` 模式将指针置首并清空文件.
> - `'a'` 模式将指针置末,所有写入都在文件末尾追加,是“追加日志”的典型选择.
> - `'r+'` 模式下,指针在开头,写入会**覆盖**原有内容(而非插入).

#### 6. 文件读写方法

##### 6.1 写入方法

###### `write(str)`:写入字符串

```python
with open("mydata.txt", "w") as f:
    f.write("飞雪连天射白鹿")
    f.write("笑书神侠倚碧鸳")
```

**结果**(连续写入,无分隔符):
```
飞雪连天射白鹿笑书神侠倚碧鸳
```

###### `writelines(序列)`:写入多个字符串

```python
with open("mydata.txt", "w") as f:
    lines = ["飞雪连天射白鹿\t", "笑书神侠倚碧鸳\n"]
    f.writelines(lines)
    f.writelines(["横批:越女剑\n"])
```

**结果**(通过字符串内的 `\t`,`\n` 控制格式):
```
飞雪连天射白鹿	笑书神侠倚碧鸳
横批:越女剑
```

##### 6.2 读取方法

###### `read()`:读取全部内容

```python
with open("mydata.txt", "r") as f:
    content = f.read()
    print(repr(content))   # '飞雪连天射白鹿\t笑书神侠倚碧鸳\n横批:越女剑\n'
```

###### `readline()`:读取一行

```python
with open("mydata.txt", "r") as f:
    line1 = f.readline()   # '飞雪连天射白鹿\t笑书神侠倚碧鸳\n'
    line2 = f.readline()   # '横批:越女剑\n'
```

###### `readlines()`:读取所有行(返回列表)

```python
with open("mydata.txt", "r") as f:
    lines = f.readlines()  # ['飞雪连天射白鹿\t笑书神侠倚碧鸳\n', '横批:越女剑\n']
```

##### 6.3 指针控制:`seek()` 与 `tell()`

| 方法 | 作用 |
|------|------|
| `f.tell()` | 返回当前指针位置(字节数) |
| `f.seek(offset, whence)` | 移动指针到指定位置 |

```python
with open("data.txt", "r") as f:
    print(f.tell())      # 0
    f.read(5)
    print(f.tell())      # 5
    f.seek(0)            # 回到开头
    print(f.tell())      # 0
```

#### 7. 追加模式与写模式对比

##### 示例:多次写入同一文件

```python
# 第一次:写模式(覆盖)
with open("log.txt", "w") as f:
    f.write("第一次写入\n")

# 第二次:写模式(覆盖)
with open("log.txt", "w") as f:
    f.write("第二次写入\n")   # 第一次内容被覆盖

# 第三次:追加模式(保留)
with open("log.txt", "a") as f:
    f.write("第三次追加\n")   # 在末尾追加
```

**最终文件内容**:
```
第二次写入
第三次追加
```

#### 8. 与数学/算法的关联

| 应用场景 | 文件操作 |
|----------|----------|
| 实验数据保存 | 将计算结果写入文本文件,便于后续分析 |
| 算法参数配置 | 从配置文件读取参数,避免硬编码 |
| 数据预处理 | 从文件读取原始数据,处理后输出 |
| 日志记录 | 用追加模式记录程序运行过程 |
| 结果持久化 | 将算法输出(如训练好的模型参数)保存 |

---

#### 9. 注意事项

| 问题 | 解决方案 |
|------|----------|
| 忘记关闭文件 | 使用 `with` 语句自动管理 |
| 路径错误 | 用 `os.path` 模块构建跨平台路径 |
| 编码问题(中文乱码) | 指定 `encoding='utf-8'` |
| 写入后立即读取为空 | 指针在末尾,需 `seek(0)` 或重新打开 |
| Windows 下 `'a'` 模式写入空行 | 使用 `newline=''`(见 CSV 部分) |

#### 10. 快速参考

```python
# 打开与关闭
f = open("data.txt", "r")
content = f.read()
f.close()

# with 语句(推荐)
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()

# 写入
with open("data.txt", "w") as f:
    f.write("Hello\n")
    f.writelines(["line1\n", "line2\n"])

# 读取
with open("data.txt", "r") as f:
    all_text = f.read()
    one_line = f.readline()
    all_lines = f.readlines()

# 指针操作
f.tell()          # 当前位置
f.seek(0)         # 回到开头
```
