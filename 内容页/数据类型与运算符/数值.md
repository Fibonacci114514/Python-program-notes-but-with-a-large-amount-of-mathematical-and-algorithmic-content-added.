> **摘要**:Python 提供了整数(`int`)和浮点数(`float`)两种基本数值类型,支持完整的算术运算,复合赋值,内置数值函数,以及强大的标准库 `math`.本文系统梳理数值类型特性,运算符含义,常用函数,并特别强调数学计算中的常见陷阱(如浮点精度,整除规则),为后续科学计算与算法实现奠定基础.

---

#### 1. 数值类型概述

##### 1.1 整数(`int`)
- 表示任意大小的整数(无精度限制,仅受内存大小影响).
- 支持十进制,二进制(`0b`),八进制(`0o`),十六进制(`0x`).
- 示例:`0`, `-42`, `0b1010`, `0x2A`.

##### 1.2 浮点数(`float`)
- 表示实数,精度与系统相关(通常为双精度,约 15–17 位有效数字).
- 采用二进制浮点表示,存在**精度误差**(如 `0.1 + 0.2 != 0.3`).
- 特殊值:`inf`(无穷大),`-inf`,`nan`(非数字).

> **与数学**:`int` 对应整数集 $ℤ$,`float` 对应实数集$ℝ$的近似表示,在数值分析中需注意舍入误差.

#### 2. 内置数值运算符

以下运算符适用于整数和浮点数,返回结果类型取决于操作数(若含浮点数则返回 `float`).

| 运算符 | 描述 | 示例 | 结果 | 数学形式 |
|--------|------|------|------|----------|
| `+`    | 加法 | `3 + 4.5` | `7.5` | $a+b$ |
| `-`    | 减法 | `12 - 4.8` | `7.2` | $a-b$ |
| `*`    | 乘法 | `2 * 5.0` | `10.0` | $a \cdot b$ |
| `/`    | 真除法(浮点) | `10 / 4` | `2.5` | $a / b$ |
| `//`   | 整除(向下取整) | `10 // 4` → `2` <br> `-10 // 4` → `-3` | 向下取整商 | $\left\lfloor a/b \right\rfloor$ |
| `%`    | 取余(模运算) | `10 % 3` → `1` <br> `3.5 % 3` → `0.5` | 余数(符号与除数相同) | $a \bmod b$ |
| `**`   | 幂运算 | `2 ** 3` → `8` <br> `4.0 ** 0.5` → `2.0` | 乘方 | $a^b$ |

**注意事项**:
- 乘法运算符 `*` 不可省略,数学中的 `4ab` 需写成 `4*a*b`.
- 整数除法 `//` 是**向下取整**,而非截断,这一点与 C/Java 不同(例如 `-10//4 = -3` 是因为 $-2.5$ 向下取整为 $-3$).
- 取余 `%` 满足恒等式:`(a // b) * b + a % b == a`.

#### 3. 复合赋值运算符

所有二元运算符均可与赋值结合,形成复合赋值,如 `a += b` 等价于 `a = a + b`.

| 运算符 | 等价形式 | 示例 |
|--------|----------|------|
| `+=`   | `a = a + b` | `x += 3` |
| `-=`   | `a = a - b` | `x -= 2` |
| `*=`   | `a = a * b` | `x *= 5` |
| `/=`   | `a = a / b` | `x /= 2.0` |
| `//=`  | `a = a // b` | `x //= 3` |
| `%=`   | `a = a % b` | `x %= 4` |
| `**=`  | `a = a ** b` | `x **= 2` |

**注意**:复合赋值中间不能有空格(如 `+=` 而非 `+ =`).

#### 4. 内置数值函数

Python 提供了若干内置函数,直接可用:

| 函数 | 描述 | 示例 |
|------|------|------|
| `abs(x)` | 绝对值 | `abs(-3.2)` → `3.2` |
| `divmod(x, y)` | 返回 `(x//y, x%y)` 的元组 | `divmod(10, 3)` → `(3, 1)` |
| `pow(x, y[, z])` | $x^y$,若 z 存在则返回 $(x^y) \bmod z$ | `pow(2, 3)` → `8`,`pow(2, 3, 5)` → `3` |
| `round(x[, n])` | 四舍五入,保留 n 位小数(省略则返回整数) | `round(3.14159, 2)` → `3.14` |
| `max(x1, x2, ...)` | 返回最大值 | `max(1, 5, 3)` → `5` |
| `min(x1, x2, ...)` | 返回最小值 | `min(1, 5, 3)` → `1` |

**特别注意 `round()` 的陷阱**:由于浮点数二进制表示,`round(2.675, 2)` 可能得到 `2.67` 而非 `2.68`(实际为 `2.674999...`),精度敏感时需使用 `decimal.Decimal`.

#### 5. 标准数学库 `math`

Python 的 `math` 库提供了丰富的数学函数与常数,需显式导入.

##### 5.1 导入方式

```python
import math                 # 使用时需加 math. 前缀
from math import pi, sqrt   # 直接使用函数名
from math import *          # 导入所有(不推荐,可能覆盖自定义函数)
```

##### 5.2 数学常数

| 常数 | 数学符号 | 值 |
|------|----------|-----|
| `math.pi` | $\pi$ | 3.141592653589793 |
| `math.e` | $e$ | 2.718281828459045 |
| `math.inf` | $\infty$ | 正无穷大 |
| `math.nan` | NaN | 非数字标记 |

##### 5.3 常用数学函数(分类)

###### 基本运算与取整
| 函数 | 数学形式 | 描述 |
|------|----------|------|
| `math.fabs(x)` | $\|x\|$ | 绝对值(返回 float) |
| `math.fmod(x, y)` | $x \bmod y$ | 浮点数取余(优于 `%`) |
| `math.fsum(iterable)` | $\sum x_i$ | 浮点数精确求和 |
| `math.gcd(a, b)` | - | 最大公约数(要求整数) |
| `math.trunc(x)` | - | 截断为整数(向 0 取整) |
| `math.modf(x)` | - | 返回小数部分和整数部分的元组 |
| `math.ceil(x)` | $\lceil x \rceil$ | 向上取整 |
| `math.floor(x)` | $\lfloor x \rfloor$ | 向下取整 |
| `math.factorial(n)` | $n!$ | 阶乘(整数) |

###### 幂,对数与平方根
| 函数 | 数学形式 | 描述 |
|------|----------|------|
| `math.pow(x, y)` | $x^y$ | 返回浮点数(比 `**` 更安全) |
| `math.exp(x)` | $e^x$ | 自然指数 |
| `math.sqrt(x)` | $\sqrt{x}$ | 平方根 |
| `math.log(x[, base])` | $\log_{\text{base}} x$ | 默认以 e 为底 |
| `math.log2(x)` | $\log_2 x$ | 以 2 为底 |
| `math.log10(x)` | $\log_{10} x$ | 以 10 为底 |
| `math.hypot(x, y)` | $\sqrt{x^2 + y^2}$ | 欧几里得距离(斜边长度) |

###### 三角函数(弧度制)
| 函数 | 数学形式 | 描述 |
|------|----------|------|
| `math.sin(x)` | $\sin x$ | 正弦 |
| `math.cos(x)` | $\cos x$ | 余弦 |
| `math.tan(x)` | $\tan x$ | 正切 |
| `math.asin(x)` | $\arcsin x$ | 反正弦(返回弧度) |
| `math.acos(x)` | $\arccos x$ | 反余弦 |
| `math.atan(x)` | $\arctan x$ | 反正切 |
| `math.atan2(y, x)` | $\arg(x+iy)$ | 从坐标角度(范围 $[-\pi, \pi]$) |

###### 角度转换
| 函数 | 描述 |
|------|------|
| `math.degrees(x)` | 弧度 → 角度 |
| `math.radians(x)` | 角度 → 弧度 |

#### 6. 典型应用示例

##### 示例 1:找零钱问题(整除与取余)

```python
money = int(input("输入金额:"))
m50 = money // 50
money %= 50
m5 = money // 5
money %= 5
m1 = money
print(f"50元:{m50}张,5元:{m5}张,1元:{m1}张")
```

##### 示例 2:计算三角形的斜边长度(勾股定理)

```python
import math
a = 3.0
b = 4.0
c = math.hypot(a, b)   # 等价于 math.sqrt(a*a + b*b)
print(c)  # 5.0
```

##### 示例 3:浮点数精度问题与规避

```python
# 错误预期
if 0.1 + 0.2 == 0.3:
    print("相等")   # 不会输出

# 正确做法:使用容差比较
epsilon = 1e-9
if abs((0.1 + 0.2) - 0.3) < epsilon:
    print("近似相等")
```

#### 7. 与数学/算法的关联

- **离散数学**:整数运算(`//`, `%`)用于数论,同余,GCD,组合计数.
- **微积分/数值分析**:浮点运算,误差分析,`math` 函数(指数,对数,三角)用于数值逼近,积分,微分方程.
- **线性代数**:`hypot` 计算欧几里得距离,为向量模长提供基础.
- **算法复杂度**:幂运算,阶乘常用于算法分析(如组合数,时间复杂度计算).

> **建议**:在进行数学计算时,优先使用 `math` 库函数(如 `sqrt` 优于 `**0.5`),因其经过高度优化且语义清晰.对于高精度计算(如金融),请使用 `decimal.Decimal` 或 `fractions.Fraction`.
