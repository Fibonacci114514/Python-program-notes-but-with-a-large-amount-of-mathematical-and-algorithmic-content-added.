> **摘要**:任何程序都需要与外界交换数据——接收输入(`input`)和呈现输出(`print`).本文详细说明 Python 中这两大基本 I/O 操作,重点分析 `input` 返回字符串的特性、`eval` 的安全隐患及替代方案,以及 `print` 的格式化技巧.理解这些内容,是编写可交互数学程序的第一步.

#### 1. 输入函数 `input()`:从键盘获取数据

##### 1.1 基本用法

```python
变量 = input("提示字符串")
```

- 执行时程序暂停,等待用户输入(以回车结束).
- **返回值始终是字符串(`str`)类型**,无论用户输入的是数字、字母还是符号.

```python
>>> name = input("请输入您的姓名:")
请输入您的姓名:张伟
>>> type(name)
<class 'str'>
```

##### 1.2 获取数值输入

由于 `input` 返回字符串,若需进行数学运算,必须进行类型转换.常见方式:

```python
# 方式一:使用 int() / float() 直接转换(推荐,类型明确)
age = int(input("请输入年龄:"))
score = float(input("请输入成绩:"))

# 方式二:使用 eval()(灵活但危险,见 §1.3)
value = eval(input("请输入表达式:"))
```

**选择建议**:

| 场景 | 推荐方式 | 原因 |
|------|----------|------|
| 明确需要整数 | `int(input(...))` | 类型清晰,直接转换 |
| 明确需要浮点数 | `float(input(...))` | 同上 |
| 需要计算表达式(如 `3+5`) | 谨慎使用 `eval` 或 `ast.literal_eval` | 动态求值,但注意安全 |

---

##### 1.3 `eval()` 的安全隐患(重要！)

`eval(input(...))` 会将用户输入作为 Python 表达式执行,这带来了**代码注入**的风险.

```python
# 危险示例
user_input = "__import__('os').system('rm -rf /')"
eval(user_input)   # 若在 Linux 下,会执行删除命令！
```

**安全使用方式**:
- **仅限学习/个人实验**:在自己的可控环境下使用.
- **生产环境**:使用 `int()` / `float()` 或 `ast.literal_eval()`(仅解析字面量,不执行代码).
- **限制命名空间**(不推荐依赖):

```python
safe_globals = {"__builtins__": None}
print(eval("2 + 3", safe_globals))   # 输出: 5,但无法调用危险函数
```

> **最佳实践**:除非你明确需要动态表达式计算,否则对用户输入应始终使用 `int()` 或 `float()` 进行明确类型转换.

#### 2. 输出函数 `print()`:显示结果

##### 2.1 基本用法

```python
print(表达式1, 表达式2, ...)
```

- 从左到右求值并输出.
- 多个表达式之间默认以**空格**分隔.
- 输出结束后默认**换行**(`end='\n'`).

```python
>>> x, y = 3, 5
>>> print("x =", x, ", y =", y)
x = 3 , y = 5
```

##### 2.2 定制分隔符和结尾

```python
print(表达式, sep='分隔符', end='结尾字符串')
```

- `sep`:指定表达式之间的分隔符,默认为一个空格.
- `end`:指定输出末尾的字符,默认为换行符 `\n`.

```python
>>> print("a", "b", "c", sep=", ", end=".\n")
a, b, c.
```

##### 2.3 格式化输出(核心技能)

在数学编程中,经常需要控制数值的显示精度、宽度和对齐方式.

######## (1)`format()` 方法(通用)

```python
print("{} 的平方是 {}".format(5, 25))
# 输出: 5 的平方是 25
```

带格式说明符:

```python
pi = 3.1415926
print("π 近似值: {:.3f}".format(pi))   # 输出: π 近似值: 3.142
print("保留 2 位小数: {:.2%}".format(0.1234))  # 输出: 保留 2 位小数: 12.34%
```

######## (2)f-string(Python 3.6+,推荐)

直接在字符串前加 `f`,用 `{变量}` 嵌入值,简洁直观.

```python
name = "张三"
score = 95.5
print(f"学生 {name} 的成绩为 {score:.1f} 分")
# 输出: 学生 张三 的成绩为 95.5 分
```

**数学计算中常用**:

```python
x = 0.1 + 0.2
print(f"0.1 + 0.2 = {x:.1f}")   # 输出: 0.1 + 0.2 = 0.3
```

#### 3. 综合示例:输入两个数,输出和与积

```python
# 安全获取输入
a = float(input("请输入第一个数:"))
b = float(input("请输入第二个数:"))

# 计算
sum_val = a + b
product = a * b

# 格式化输出
print(f"和:{sum_val:.2f},积:{product:.2f}")
```

运行示例:

```
请输入第一个数:3.5
请输入第二个数:2.8
和:6.30,积:9.80
```

#### 5. 安全警示总结

| 方式 | 安全性 | 适用场景 |
|------|--------|----------|
| `int(input())` | ✅ 安全 | 明确需要整数 |
| `float(input())` | ✅ 安全 | 明确需要浮点数 |
| `eval(input())` | ❌ 危险(可能注入) | 仅供个人学习,不用于生产环境 |
| `ast.literal_eval(input())` | ⚠️ 相对安全 | 解析合法字面量(列表/字典/数字/字符串) |

> **作为算法学习者和数学爱好者,请养成使用 `int()`/`float()` 的习惯,这不仅能避免安全风险,也使代码意图更加清晰.**

```python
# 格式化

```
