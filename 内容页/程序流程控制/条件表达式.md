> **摘要**:条件表达式是程序分支和循环的决策核心.本文系统梳理关系运算符,逻辑运算符及其在 Python 中的特有用法(如连写),并给出多个数学/算法中的典型条件构造示例,帮助读者写出清晰,正确的逻辑判断.

---
#### 1. 关系运算符(比较运算)

关系运算符用于比较两个值的大小或相等关系,返回布尔值 `True` / `False`.

假设 `a = 10`, `b = 20`:

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| $$`==`$$ | 相等 | `a == b` | `False` |
| `!=` | 不等 | `a != b` | `True` |
| `>` | 大于 | `a > b` | `False` |
| `<` | 小于 | `a < b` | `True` |
| `>=` | 大于等于 | `a >= b` | `False` |
| `<=` | 小于等于 | `a <= b` | `True` |

##### 1.1 Python 特有:关系运算符连用

Python 允许数学中的连续比较写法,这与其他许多语言不同.

```python
x = 5
print(1 < x < 10)      # True
print(0 < x < 5)       # False
```

等价于 `(1 < x) and (x < 10)`,但更直观易读.

#### 2. 逻辑运算符

用于组合多个条件,形成更复杂的布尔表达式.

| 运算符 | 含义 | 示例 | 结果 |
|--------|------|------|------|
| `and` | 逻辑与(并且) | `(a > 0) and (b > 0)` | 二者均为 True 时返回 True |
| `or` | 逻辑或(或者) | `(a < 0) or (b < 0)` | 至少一个为 True 时返回 True |
| `not` | 逻辑非(取反) | `not (a > 0)` | 将 True 变 False,反之亦然 |

**注意**:
- `and` 和 `or` 具有短路特性(`and` 遇假即停,`or` 遇真即停).
- 在 Python 中,`and` 返回最后一个求值的表达式,`or` 亦然,这在某些情况下可用于条件赋值(但不建议滥用).

---

#### 3. 运算符优先级(从高到低)

| 类别 | 运算符 |
|------|--------|
| 括号 | `( )` |
| 算术运算 | `**`, `*`, `/`, `//`, `%`, `+`, `-` |
| 关系运算 | $`==`$, `!=`, `>`, `<`, `>=`, `<=` |
| 逻辑运算 | `not`, `and`, `or` |

> **建议**:如果不确定优先级,**使用括号明确**,增强可读性.

#### 4. 典型数学条件构造

##### 4.1 判断偶数

```python
x % 2 == 0
```

##### 4.2 判断 3 的倍数且个位为 5

```python
x % 3 == 0 and x % 10 == 5
```

##### 4.3 判断三条边能否构成三角形

```python
(a + b > c) and (b + c > a) and (a + c > b) and (a > 0) and (b > 0) and (c > 0)
```

##### 4.4 判断闰年

```python
(year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)
```

##### 4.5 判断一个数是否在区间 $[L, R]$ 内

```python
L <= x <= R
```

##### 4.6 判断字符是否为字母

```python
('a' <= ch <= 'z') or ('A' <= ch <= 'Z')
# 或使用内置方法
ch.isalpha()
```

---

#### 5. 常见陷阱

| 陷阱 | 说明 |
|------|------|
| `=` 与 $$`==`$$ 混淆 | `=` 是赋值,$`==`$ 是比较.`if x = 5:` 会报语法错误(在 Python 中不允许) |
| 浮点数比较 | 不要直接用 $$`==`$$ 比较浮点数,应使用容差:`abs(a - b) < 1e-9` |
| 逻辑运算符与整数 | 非零整数在布尔上下文中视为 `True`,`0` 视为 `False` |
| `not` 优先级高于比较 | 例:`not x == 0` 等价于 `not (x == 0)`,而非 `(not x) == 0` |

#### 6. 与离散数学的关联

| 数学概念 | Python 对应 |
|----------|-------------|
| 命题逻辑 | 布尔表达式 |
| 逻辑与($∧$) | `and` |
| 逻辑或($∨$) | `or` |
| 逻辑非($¬$) | `not` |
| 关系谓词 | $`==`$, `<`, `>`, `<=`, `>=` |
| 量词($∀, ∃$) | 通常由循环 + 条件组合实现 |
| 集合成员 | `in` 运算符 |
