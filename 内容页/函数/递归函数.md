> **摘要**:递归是函数调用自身的编程技术,其核心思想来源于数学中的归纳定义.递归函数由终止条件(base case)和递归步骤(recursive step)组成,适用于具有自相似结构的问题.本文系统介绍递归的工作原理,并通过阶乘,斐波那契数列等经典示例展示递归的写法,同时探讨递归与计算理论中 **递归函数论** 的深刻联系.

---

#### 1. 递归的定义

**递归** 是指函数在其定义中调用自身.这种方法将大问题分解为结构相同但规模更小的子问题,是分治思想的基础.

> **与计算理论的关联**:递归是计算理论的核心概念之一.**原始递归函数** 和 **部分递归函数** 构成了可计算性理论的重要部分,与哥德尔不完备定理,图灵机的计算能力有深刻联系.递归函数可以表达任何可计算函数(图灵完备).

---

#### 2. 递归的基本结构

每个递归函数必须包含两个关键部分:

| 部分 | 作用 | 类比(数学归纳法) |
|------|------|-------------------|
| **终止条件** | 当问题规模足够小时直接返回结果,不再递归 | 归纳基础(n = 0 或 n = 1) |
| **递归步骤** | 将问题分解为更小的子问题,并调用自身 | 归纳步骤(从 n-1 推出 n) |

> 数学归纳法:若命题对基础情形成立,且假设对 k 成立可推出对 k+1 成立,则命题对所有自然数成立.递归正是这一逻辑在编程中的直接实现.

#### 3. 经典示例:阶乘(Factorial)

**数学定义**:
$$
n! = \begin{cases}
1, & n = 0 \text{ 或 } n = 1 \\
n \times (n-1)!, & n > 1
\end{cases}
$$

**递归实现**:

```python
def fact(n):
    if n == 1:          # 终止条件
        return 1
    else:               # 递归步骤
        return n * fact(n - 1)

# 输出 1~9 的阶乘
for i in range(1, 10):
    print(f"{i}! = {fact(i)}")
```

**执行过程(`fact(5)`)**:

```
fact(5)
→ 5 * fact(4)
→ 5 * (4 * fact(3))
→ 5 * (4 * (3 * fact(2)))
→ 5 * (4 * (3 * (2 * fact(1))))
→ 5 * (4 * (3 * (2 * 1)))
→ 120
```

#### 4. 经典示例:斐波那契数列(Fibonacci)

**数学定义**:
$$
F(n) = \begin{cases}
1, & n = 1 \text{ 或 } n = 2 \\
F(n-1) + F(n-2), & n > 2
\end{cases}
$$

**递归实现**:

```python
def fibo(n):
    if n == 1 or n == 2:    # 终止条件
        return 1
    else:                   # 递归步骤
        return fibo(n - 1) + fibo(n - 2)

# 输出前20项,每行5个
for i in range(1, 21):
    print(f"{fibo(i):>8}", end="  " if i % 5 != 0 else "\n")
```

**注意**:这种朴素递归存在大量的重复计算(如 `fibo(3)` 被多次计算),效率很低($O(2^n)$).实际应用中可用**记忆化(Memoization)** 或动态规划优化.

```python
# 记忆化优化
from functools import lru_cache

@lru_cache(maxsize=None)
def fibo_opt(n):
    if n == 1 or n == 2:
        return 1
    return fibo_opt(n - 1) + fibo_opt(n - 2)
```

#### 5. 递归与循环的对比

| 维度 | 递归 | 循环 |
|------|------|------|
| 思想 | 自顶向下分解 | 自底向上累积 |
| 代码 | 简洁,接近数学定义 | 显式,有时较冗长 |
| 性能 | 函数调用有开销,可能栈溢出 | 无函数调用开销,更高效 |
| 适用 | 树/图遍历,分治,数学归纳 | 简单重复,数列求和 |
| 可读性 | 对自相似问题直观 | 对迭代过程直观 |

#### 6. 递归的经典问题:汉诺塔

汉诺塔是递归的经典应用.将 n 个盘子从 A 移到 C,借助 B:

```python
def hanoi(n, a, b, c):
    if n == 1:
        print(f"{a} → {c}")
    else:
        hanoi(n - 1, a, c, b)   # 将 n-1 个盘子从 A 移到 B
        print(f"{a} → {c}")     # 将第 n 个盘子从 A 移到 C
        hanoi(n - 1, b, a, c)   # 将 n-1 个盘子从 B 移到 C

hanoi(3, "A", "B", "C")
```

#### 7. 递归与计算理论的深层关联

递归不仅是编程技巧,更是计算理论的基石之一:

- **原始递归函数**:由基础函数(零函数,后继函数,投影函数)通过复合和原始递归操作构造,能表达大多数常见函数(如阶乘,加法,乘法).
- **部分递归函数**:扩展了原始递归,允许使用 $μ$ 算子(最小化操作),可表达所有可计算函数,与图灵机等价(**邱奇-图灵论题**).
- **自我指涉**:递归函数的自调用特性,与哥德尔编码中的自指命题,形式系统中的不动点有深刻的逻辑联系.
- **停机问题**:递归函数的“非终止”可能性(死递归)对应停机问题不可判定性.

> 当你写递归函数时,你不仅在编程,还在实践可计算性理论的核心思想.

---

#### 8. 递归的注意事项

| 问题 | 建议 |
|------|------|
| 无限递归 | 务必确保终止条件最终能到达 |
| 栈溢出 | Python 默认递归深度约 1000,可用 `sys.setrecursionlimit()` 调大 |
| 重复计算 | 用记忆化或动态规划优化(如斐波那契) |
| 性能开销 | 递归有函数调用开销,循环通常更快 |

#### 9. 快速参考

```python
# 递归模板
def recursive_func(参数):
    if 终止条件:          # base case
        return 直接结果
    else:
        # 分解为子问题
        return 组合(recursive_func(子参数))

# 设置递归深度
import sys
sys.setrecursionlimit(10000)
```

> **总结**:递归是将数学归纳法转化为可执行代码的最直接方式.它让程序能够用简洁的方式表达具有自相似结构的问题(如树遍历,分治算法,组合数学).理解递归不仅有助于编写更优雅的代码,更为深入理解计算理论——从原始递归函数到图灵完备性——提供了直观的起点.
