> **摘要**:变量的作用域决定了它在程序的哪些部分可以被访问.Python 中主要有两种作用域:全局作用域(整个模块可见)和局部作用域(函数内部可见).本文系统介绍局部变量和全局变量的区别,同名变量的优先级规则,以及 `global` 声明的用法,帮助读者理解变量生命周期与命名空间的管理.

---
#### 1. 作用域的基本概念

**作用域(Scope)** 是指变量在程序中可以被访问的区域.每个变量都有自己的作用域,决定了它在哪些代码段中是合法的.

- **局部变量**:在函数内部定义的变量,只能在函数内访问.
- **全局变量**:在函数外部(模块顶层)定义的变量,整个模块可见.

> **与计算理论的关联**:作用域对应数学逻辑中的 **量词辖域(scope of quantifier)** ——一个变量的“有效范围”.在 λ 演算中,变量可以是自由的(free)或绑定的(bound),Python 的全局/局部变量划分正是这一概念的编程实现.

---

#### 2. 局部变量

在函数内部赋值的变量默认为局部变量,其作用域仅限于该函数内部.

```python
def f():
    x = 10          # 局部变量
    return x * x

print(f())          # 100

# 在函数外访问 x —— 报错
print(x)            # NameError: name 'x' is not defined
```

**规则**:函数执行结束后,局部变量被销毁,无法在外部访问.

---

#### 3. 全局变量

在函数外部(模块顶层)赋值的变量为全局变量,整个模块可见(包括函数内部).

```python
x = 10              # 全局变量

def f():
    return x * x    # 可访问全局变量 x

print(f())          # 100
print(x)            # 10
```

全局变量在程序运行期间持续存在,直到程序结束或被显式删除.

---

#### 4. 全局变量与局部变量同名(优先级规则)

当全局变量和局部变量同名时,**局部变量优先**(在函数内部屏蔽全局变量).

```python
x = 10              # 全局变量

def f():
    x = 5           # 局部变量(与全局同名)
    print(f"函数内 x = {x}")   # 5
    return x * x

print(f())          # 25
print(f"函数外 x = {x}")      # 10(全局变量未改变)
```

**图示**:

```
全局作用域         局部作用域(函数 f 内部)
┌─────────────┐   ┌─────────────────┐
│ x = 10      │   │ x = 5           │ ← 屏蔽全局 x
│             │   │ return x * x    │
│ print(x)    │   └─────────────────┘
└─────────────┘
     ↓
  输出 10
```

---

#### 5. `global` 声明:在函数内修改全局变量

默认情况下,在函数内对变量赋值会创建局部变量,而非修改全局变量.若需在函数内修改全局变量,需使用 `global` 关键字声明.

```python
x = 10              # 全局变量

def f():
    global x        # 声明 x 为全局变量
    x = 5           # 修改全局变量 x
    print(f"函数内 x = {x}")

f()                 # 函数内 x = 5
print(f"函数外 x = {x}")    # 5(全局变量被修改)
```

**使用场景**:
- 需要在函数内部更新全局状态(如计数器,配置变量).
- 但应谨慎使用,过多全局变量会降低代码可读性和可维护性.

---

#### 6. 嵌套函数中的作用域(`nonlocal`)

在函数内部定义函数时,内层函数可以访问外层函数的局部变量(闭包).若需修改外层局部变量,使用 `nonlocal` 声明.

```python
def outer():
    x = 10
    def inner():
        nonlocal x   # 声明 x 来自外层作用域
        x = 20
    inner()
    print(x)         # 20

outer()
```

> 此特性在实现装饰器,闭包等高级功能时非常重要.

---

#### 7. 作用域与命名空间的层次结构

Python 的作用域遵循 **LEGB 规则**(从内到外查找):

| 层级 | 缩写 | 含义 |
|------|------|------|
| 局部 | Local | 函数内部定义的变量 |
| 闭包 | Enclosing | 外层嵌套函数的局部变量 |
| 全局 | Global | 模块顶层定义的变量 |
| 内置 | Built-in | Python 内置作用域(`print`,`len` 等) |

> **与计算理论的关联**:LEGB 查找规则类似于 **λ 演算中的自由变量绑定机制**——变量在其最近的绑定处被解析,若未绑定则为自由变量.这种机制确保了变量在复杂嵌套结构中的正确解析.

---

#### 8. 注意事项与最佳实践

| 问题 | 建议 |
|------|------|
| 函数内意外修改全局变量 | 如需修改,显式使用 `global` 声明 |
| 全局变量过多 | 尽量将变量作为参数传递,避免全局状态 |
| 局部变量与全局变量同名 | 避免同名,减少混淆 |
| 在循环/分支中赋值 | 这些结构不创建新作用域,变量归所在函数或模块管理 |

---

#### 9. 快速参考

```python
# 局部变量
def f():
    x = 10        # 仅在 f 内可见

# 全局变量
g = 20            # 整个模块可见

def h():
    print(g)      # 可读取全局变量

def modify():
    global g      # 声明才能修改
    g = 30

# LEGB 查找顺序
print(len([1,2,3]))  # len 来自 Built-in
```

---

> **总结**:作用域是管理变量可见性的核心机制,其思想与计算理论和数理逻辑中的变量绑定规则一脉相承.局部变量隔离了函数的内部状态,全局变量则提供了跨函数的数据共享.理解并善用作用域规则,既能避免命名冲突,也能写出更清晰,更可维护的代码.
