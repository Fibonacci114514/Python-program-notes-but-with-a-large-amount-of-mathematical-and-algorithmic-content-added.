> **摘要**:函数是组织代码,实现复用的基本单元.本文通过 `round()` 函数引入函数的核心要素——函数名,参数(形参),返回值——并说明自定义函数的定义语法,帮助读者建立对函数的整体认知.

---

#### 1. 函数是什么?

函数是一段组织好的,可重复使用的代码块,用于完成特定的任务.

**函数的优点**:
1. 代码复用,减少重复.
2. 将复杂问题分解为子问题.
3. 提高代码整洁度和可读性.

> **与数学的关联**:函数对应数学中的映射 $y = f(x)$:给定输入(参数),经过处理,产生输出(返回值).

> **与计算理论的关联**:函数是程序模型的基本构件.在可计算性理论中,函数(尤其是递归函数)构成了计算模型的核心对象,研究哪些函数是“可计算的”.

---

#### 2. 函数的要素:以 `round()` 为例

Python 内置函数 `round()` 用于对浮点数四舍五入.

```python
round(3.14159, 2)   # 3.14
```

**分析**:
- **函数名**:`round`
- **形式参数(形参)**:`x`(要四舍五入的数)和 `n`(保留小数位数,可选)
- **返回值**:四舍五入后的浮点数(当 `n` 省略时返回整数)
- **实参**:调用时传入的 `3.14159` 和 `2`

#### 3. 自定义函数的语法

```python
def 函数名([参数列表]):
    函数体
    return 返回值
```

**要点**:
1. 即使无参数,也必须保留空括号 `()`.
2. 冒号 `:` 不可省略.
3. 函数体必须**缩进**(通常 4 个空格).
4. `return` 语句可选；可有多条,执行到第一条即结束函数.
5. 若无 `return`,函数返回 `None`.

**示例**:

```python
def greet(name):
    print(f"Hello, {name}!")

def square(x):
    return x * x

def add(a, b):
    return a + b

def empty():
    pass   # 占位,什么都不做
```

---

#### 4. 形参与实参

- **形参(形式参数)**:定义函数时括号中指定的参数名,用于接收传入的数据.
- **实参(实际参数)**:调用函数时实际传递的值.

```python
def add(a, b):    # a, b 是形参
    return a + b

result = add(3, 5)   # 3, 5 是实参
```

实参与形参**按位置一一对应**——第一个实参传给第一个形参,依此类推.

---

#### 5. 返回值的处理

- 有返回值:函数调用可出现在表达式中(如 `print(add(3,5))`).
- 无返回值:函数只能作为单独语句调用(如 `greet("张三")`).

```python
# 有返回值
total = add(3, 5)          # 用于赋值
print(add(10, 20))         # 用于打印

# 无返回值
greet("李四")              # 只能单独调用
```

#### 6. 函数的两种身份(数学/计算理论视角)

| 视角 | 函数的含义 |
|------|-----------|
| 数学 | 从输入集合到输出集合的映射 |
| 编程 | 可重复调用的代码块,可接收参数并返回结果 |
| 计算理论 | 由基本操作组合而成的**计算过程**,函数本身也是数据(可作为参数或返回值) |

> 在函数式编程语言中,函数被视为“一等公民”,可以像数据一样传递和操作——这与 λ 演算中函数是唯一基本构造物的思想一致.

#### 7. 快速参考

```python
# 无参无返回值
def f(): print("Hello")

# 有参无返回值
def f(name): print(name)

# 无参有返回值
def f(): return 42

# 有参有返回值
def f(a, b): return a + b

# 多条 return 语句
def sign(x):
    if x > 0: return 1
    elif x < 0: return -1
    else: return 0
```
